## 本轮修复

1. 为退款任务、退款完成比较和 `payment.refunded` outbox 的 PostgreSQL 动态参数补齐显式类型。
2. 让退款任务重试接受已进入 `processing` 的售后状态，避免成功转态后的任务重试被误判冲突。
3. 命令事务在开启 SERIALIZABLE 快照前按稳定顺序取得审计/共享库存锁；同进程同键请求先在连接池外排队，数据库咨询锁继续承担跨进程协调。
4. 注册角色与作用域的 `effective_at` 使用事务时间戳，避免容器时钟微调造成边界倒序。
5. 修正压测口径：首次请求与幂等重放不再同时叠加成 200 个请求；测试商品、绑定与发布的生效时间固定在明确过去，避免夹具卡在“刚刚生效”的时钟边界。
6. 压测入口同步最新身份 Realm 与 SFL 节点上下文，验证链路与当前生产入口解析保持一致。

# AU-307｜Compatibility 目录治理 RLS

该迁移为分类规则、人工审查队列、供应商分类映射和分类树四张内部运营表启用 RLS，并撤销 `anon` 与 `authenticated` 的全部表权限。静态检索未发现浏览器角色对这些表的直连读取或写入入口；目录对外读取继续经已登记的 `security definer`、仅授权 service role 的 RPC 投影。

分类器回填、人工审查队列及有效三级分类路径验证仍在数据库内消费这些治理数据，因此该迁移是现行目录链的 G0 边界措施，而不是无用权限配置。

未发现新增 P0–P3 问题；本项为静态权限与调用链审阅，未执行运行验证。

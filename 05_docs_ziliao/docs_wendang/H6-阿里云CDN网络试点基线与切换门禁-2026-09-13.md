## 5. 目标设计与缓存边界

第 4 节的通道准备门禁已经变绿，已落地链路如下；公网切流前 Cloudflare DNS 仍指向原 Tunnel：

```text
中国用户
  -> Cloudflare 权威 DNS（仅 H6 记录改为 DNS-only）
  -> 阿里云分配的 H6 CDN CNAME
  -> 中国内地 CDN 节点
  -> H6 专用 HTTP 源站 123.57.232.253:4480
     Host = h6-origin.hbbtzn.com
  -> 节点网关 HTTPS 127.0.0.1:4430
  -> Node/vinext SSR :4410
```

客户端到 CDN 使用已部署的 DigiCert HTTPS 证书；CDN 到独立源站固定使用 HTTP 4480，因此该段不存在 SNI。专用 Caddy 只接受 `h6-origin.hbbtzn.com`，再转发到现有节点网关，不改变共享站点块。

H6 首批缓存策略应采用“默认动态、只明确放行带内容哈希的静态资源”：

| 请求 | CDN 策略 | 验收点 |
| --- | --- | --- |
| `/`、`/h5`、所有页面/深链 | 不缓存 | 每次回源；响应不能被 CDN 改成可缓存 |
| SSR/RSC 请求及查询参数变体 | 不缓存，保留完整查询参数 | 不混用不同页面状态 |
| HTML 内联 `window.__SFL_STOREFRONT_IDENTITY_NODE_REGISTRY__` | 随 HTML 不缓存 | 不出现旧节点配置 |
| 同域公开商品目录 | 尊重源站 `public, max-age=30` | 30 秒内命中，过期后重新验证源站 |
| 身份、会员、购物车、订单、结算、支付 | 仍走 `api.hbbtzn.com`，不进入 H6 CDN | 不改变现有跨域 API 与登录态链路 |
| 登录、会话、OAuth/微信回调、跳转响应 | 不缓存 | `Set-Cookie`、Location 与状态码保持正确 |
| 含 `Cookie` 或 `Authorization` 的请求 | 绕过缓存 | 回源响应不得进入共享缓存 |
| `/assets/*` 中经制品证明带内容哈希的文件 | `public, max-age=31536000, immutable` | 第二次请求命中；URL 内容不可变 |
| 其他图片/字体/脚本 | 默认不放行长期缓存 | 只有确认版本化后再单独配置 TTL |

已开启“源站缓存优先”，并保持“忽略源站不缓存标头”为关闭；因此 HTML 的 `no-store`、公开商品的 30 秒和哈希静态资源的一年不可变缓存均由源站语义决定。参见[缓存过期时间](https://help.aliyun.com/zh/cdn/user-guide/configure-the-cdn-cache-expiration-time)。

## 6. Cookie、CORS 与 API 边界

- H6 页面仍以 `https://h6.hbbtzn.com` 为浏览器 origin；CNAME 切换不能改变可见 Host 或 scheme。
- SDK 请求使用 `credentials: include`，并禁止自动跟随 API 重定向；身份 Cookie 为 `Secure; HttpOnly; SameSite=Strict; Path=/` 的 host-only Cookie。
- 生产 API 的允许 origin 必须实际包含 `https://h6.hbbtzn.com`，不能只依据仓库示例判断。
- 必须实测：匿名商品、登录、ticket exchange、session read、退出、会员数据、购物车、下单前置请求、微信/OAuth 回跳。
- H6 的大部分身份与交易 API 仍访问 `api.hbbtzn.com`。只切 H6 页面到阿里云 CDN，并不会自动消除 API 仍走 Cloudflare/LAX 的延迟；本试点只能测出文档、静态资源及 H6 同域公开 API 的改善。

## 8. 回滚

当前已捕获的恢复目标是第 3.1 节的 Cloudflare Tunnel CNAME，且该目标现在已通过 H6 公网基础验收。业务工程确认本轮生产接线回滚点均已保留；正式切换阿里云 CNAME 前仍须再次导出动作当下的 DNS 记录 ID 与完整值，并演练只恢复 H6。

触发以下任一情况，只恢复 H6 原记录，不改其他域名：

- DNS/CNAME 不一致；
- 证书、Host/SNI、重定向错误；
- 任何关键页面出现 404、421 或 5xx；
- 登录、Cookie、CORS、回调或用户数据异常；
- 动态内容命中共享缓存；
- 监控不可见或无法区分边缘与回源错误。

回滚后以权威 DNS、公共 DoH、H6 页面/API 和 Cloudflare 单域流量重新验收。未完成回滚演练前，门禁保持红灯。

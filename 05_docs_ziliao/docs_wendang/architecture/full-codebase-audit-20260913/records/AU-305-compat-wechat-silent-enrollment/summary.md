# AU-305｜Compatibility 微信静默入会

微信会话路由先由微信服务器交换一次性 code，再仅以 AppID/OpenID 查询既有身份；没有已绑定身份时，才调用静默入会 RPC。RPC 使用 AppID/OpenID advisory transaction lock，插入身份记录后以行锁处理竞争；已绑定且 active 的会员原样返回，已撤销、UnionID 冲突或遗留竞争均明确拒绝，不会猜测、合并或认领既有会员。

首次入会的 tenant、enterprise 和 mall 只来自服务端按 `PUBLIC_MALL_SLUG` 查询出的 active 公开商城；小程序不提交这些边界。该事务建立零余额账户、self scope、基础公开会员角色和审计记录；其权限仅为目录和订单读取/创建，企业资格与手机认证仍由后续订单边界复核。测试覆盖冷启动单次建档与既有微信会员不重复创建。

本批次未见 P0。F-0235（P2）记录了同一路由审阅中确认的共享登录失败 IP 锁定：连续五次失败阻断 15 分钟，影响微信绑定、登录和二次验证，且与项目既定身份规则冲突；该问题需第二轮独立复核。因审计工作树缺少 Vitest 依赖，未执行相关测试。

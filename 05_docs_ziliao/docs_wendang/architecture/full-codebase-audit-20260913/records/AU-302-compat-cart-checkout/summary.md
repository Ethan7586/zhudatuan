# AU-302｜Compatibility 购物车与结算闭环

购物车读取 RPC 以 tenant、mall、用户和 membership 为范围，逐项调用资格判定，返回商品、SKU、库存、价格和可购买状态的服务端投影；前端不能以缓存投影绕过下单时的复核。路由层只以 service role 调用 RPC，且创建订单前要求 `order.create` 权限、手机号已验证、收货信息加密密钥及有效幂等键。

结算 wrapper 以订单幂等键取得事务 advisory lock；命中同请求会返回原响应且报告零个新增清除项，不同请求哈希会拒绝。首次请求委托既有订单 RPC 重验手机号、商品资格、价格和库存，创建订单与写入审计证据后才在同一数据库事务内删除该用户、租户、mall 范围内已下单 SKU 的购物车项；任一异常会使本次事务回滚。测试覆盖订单成功后的指定 RPC 组合及手机号保证边界。

未发现新增 P0–P3 问题。因审计工作树缺少 Vitest 依赖，未执行相关测试；结论基于迁移、路由和测试代码的静态调用链取证。

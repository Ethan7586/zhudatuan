# 智慧翼 Smart Wing 统一 VI 1.0

状态：**项目正式基线**  
生效日期：2026-08-13  
适用范围：iOS、Android、微信小程序、移动 H5、员工商城、统一登录、运营后台、合作商核验端及对外项目材料

视觉总板：[`design-previews/smart-wing-unified-mobile-vi-1.0.png`](./design-previews/smart-wing-unified-mobile-vi-1.0.png)

## 1. 品牌核心

### 1.1 品牌名称

- 中文品牌：**智慧翼**
- 英文品牌：**Smart Wing**（保留空格，禁止写成 `SmartWing`）
- 产品全称：**智慧翼企业福利商城**
- 移动端核心功能：**翼码**

### 1.2 品牌主张

> **让每一份福利，被看见、被理解、被善用。**

“被看见”对应透明的福利资产、资格与规则；“被理解”对应可解释的消费洞察；“被善用”对应实体券、额度规划和可执行的 AI 建议。

### 1.3 品牌性格

| 属性 | 表达                           | 禁止走向                     |
| ---- | ------------------------------ | ---------------------------- |
| 可信 | 清晰边界、真实状态、可解释规则 | 银行式冰冷、权威压迫         |
| 智能 | 适时建议、依据透明、行动闭环   | 紫色炫光、无处不在的 AI 闪光 |
| 温暖 | 关注员工所得与真实生活场景     | 甜美幼稚、餐饮网红风         |
| 高效 | 信息层级明确、关键动作短路径   | 堆满按钮、复杂仪表盘         |
| 开放 | 合作商中立接入、平台级能力     | 未授权冒用合作商标识         |

## 2. 标志系统

### 2.1 唯一母版

唯一标志母版为蓝色圆角方形中的白色翼形 `W`：

- `packages/design/src/brand/brand-mark.svg`
- `packages/design/src/brand/brand-lockup-horizontal.svg`

W 同时表达 `Wing`、双翼连接和企业/员工双向价值。现阶段不重新设计 Logo；任何新资产都从该 SVG 母版生成。

### 2.2 标志组合

1. **主标志**：方形图标，适用于 App 图标、头像、favicon、翼码入口附近的小型品牌识别。
2. **横向组合**：主标志 + `智慧翼 Smart Wing`，适用于启动页、登录页、官网和正式材料。
3. **产品组合**：主标志 + `智慧翼企业福利商城`，适用于商城头部与对外产品介绍。

### 2.3 安全空间与最小尺寸

- 图标四周安全空间不得小于图标宽度的 `1/4`。
- 数字界面主标志最小 `24px / 24pt / 48rpx`。
- 横向组合最小宽度 `120px / 120pt / 240rpx`。
- 产品组合最小宽度 `160px / 160pt / 320rpx`。
- 小于横向组合最小尺寸时，只使用主标志。

### 2.4 禁止行为

- 禁止拉伸、压扁、旋转、描边或添加外发光。
- 禁止改变 W 与圆角方形的相对比例。
- 禁止用合作商颜色替换智慧翼蓝。
- 禁止把标志放进复杂照片而没有足够对比。
- 禁止在同一界面重复堆叠多个完整品牌组合。
- 禁止让生成式 AI 重画或“优化”正式 Logo。

## 3. 品牌架构与联合品牌

品牌层级固定为：

1. **智慧翼**：平台、身份、会员、资格、资产、订单与售后。
2. **企业/福利计划**：当前员工所属企业和福利方案。
3. **合作商/履约方**：商品来源、门店、配送、核销与售后责任方。

未取得书面授权前：

- 合作商使用“合作商 A / 合作商 B”或文字名称的中性标签。
- 不使用合作商 Logo、专属色、口号和近似官方页面。
- 不出现“官方合作”“官方授权”等暗示性文案。

取得授权后，合作商 Logo 只进入固定的来源/履约区域，不支配页面背景和主按钮。智慧翼始终承担主品牌与交易责任说明。

## 4. 色彩系统

### 4.1 品牌与中性色

| 角色     | 色值      | 用途                               |
| -------- | --------- | ---------------------------------- |
| 智慧蓝   | `#1F5EFF` | 主按钮、选中态、翼码、关键品牌强调 |
| 交互深蓝 | `#174ED1` | 智慧蓝的按压/悬停状态              |
| 深海蓝   | `#143A8F` | 品牌渐变、会员卡、可信赖场景       |
| 夜空蓝   | `#07182F` | 深色背景、正式演示标题区           |
| 浅品牌蓝 | `#EAF1FF` | 选中背景、资格解释、轻提示         |
| 云雾白   | `#F5F7FA` | 页面背景                           |
| 卡片白   | `#FFFFFF` | 卡片、底栏、弹层                   |
| 正文墨   | `#172033` | 标题、正文                         |
| 次级文字 | `#475569` | 次级正文                           |
| 辅助灰   | `#64748B` | 标签、辅助信息                     |
| 边框灰   | `#E2E8F0` | 卡片与控件边框                     |

品牌渐变固定为：`135deg, #1F5EFF 0%, #143A8F 100%`。

### 4.2 状态色

| 状态        | 基础色    | 可读前景  | 浅背景    |
| ----------- | --------- | --------- | --------- |
| 成功/可用   | `#0F9F6E` | `#087A55` | `#ECFDF5` |
| 提醒/待处理 | `#F59E0B` | `#92400E` | `#FFF7E6` |
| 风险/失败   | `#DC2626` | `#B91C1C` | `#FEF2F2` |

状态色只表达语义，不作为大面积品牌主色。文字和图标使用 `Strong` 颜色，浅背景使用 `Surface` 颜色；不得仅靠颜色表达状态。

### 4.3 暗色模式

- 页面背景 `#07182F`，卡片 `#10294D`，次级卡片 `#14345D`。
- 正文 `#F8FAFC`，次级文字 `#E2E8F0`，边框 `#334155`。
- 动态二维码无论主题如何始终使用纯白底与高对比黑码。
- 暗色模式不是简单反色；商品图、会员卡与状态色保持品牌含义。

## 5. 字体与数字

### 5.1 字体族

- iOS 中文：`PingFang SC`
- Android 中文：`Noto Sans SC`，缺失时回退系统中文字体
- 微信小程序中文：系统中文字体，优先 `PingFang SC / Microsoft YaHei`
- 拉丁与数字：`Inter`，平台不可用时回退系统 Sans
- 技术凭证：`SFMono-Regular / Roboto Mono / Consolas`

禁止使用书法字体、手写体、仿宋作为功能界面字体。正式金融与支付金额使用等宽数字特性。

### 5.2 统一层级

| 样式       | 大小/行高 | 字重 | 场景                   |
| ---------- | --------- | ---- | ---------------------- |
| Display    | `32/40`   | 700  | 活动主标题、品牌大标题 |
| H1         | `28/36`   | 700  | 页面主标题、关键金额   |
| H2         | `20/28`   | 600  | 模块标题               |
| H3         | `17/24`   | 600  | 卡片标题               |
| Body       | `16/24`   | 400  | 正文                   |
| Body Small | `14/20`   | 400  | 列表与说明             |
| Caption    | `12/18`   | 400  | 标签和辅助信息         |

系统字号放大后页面不得截断关键内容；金额、会员状态和资格原因必须保持可读。

## 6. 网格、圆角与阴影

- 基础网格 `8`，允许 `4` 的半步。
- 页面横向安全边距：iOS/Android `16pt/dp`，小程序 `32rpx`。
- 圆角：小 `8`、控件 `12`、卡片 `16`、会员卡/大弹层 `24`。
- 普通卡片优先使用 `1px` 边框；阴影只用于浮层、中央翼码、会员卡和高层级容器。
- 不使用连续多层重阴影，不使用玻璃拟态作为主视觉。

## 7. 图标、插画与摄影

### 7.1 图标

- 统一使用 `2px` 圆角线性图标。
- 标准尺寸 `24`，紧凑尺寸 `20`，小标签 `16`。
- 激活状态可使用智慧蓝轻填充，但不混用多套图标风格。
- 翼码使用专属图标：`packages/design/src/brand/wing-code-symbol.svg`。

### 7.2 品牌翼纹

`packages/design/src/brand/wing-pattern.svg` 是会员卡、深色标题区和活动背景的辅助图形。透明度控制在 `8%–34%`，禁止与正文争抢视觉层级。

### 7.3 摄影

- 商品图使用中性、干净、冷自然光和真实材质。
- 生活方式图体现真实中国员工、家庭、办公与健康场景。
- 不过度磨皮，不制造奢侈品距离感，不把福利商城拍成餐饮网红店。
- 未授权合作商品牌不得作为视觉中心。
- 图片失败必须显示智慧翼本地占位图，禁止破图图标。

### 7.4 AI 视觉

AI 功能使用智慧蓝圆形 `AI` 标记和翼形线纹，不额外建立紫色渐变品牌。每条建议标明“AI 建议”、依据和可执行动作；禁止用星光动画制造虚假确定性。

## 8. 翼码品牌签名

翼码是三端统一的核心产品资产，不是普通二维码组件。

### 8.1 中央入口

唯一导航：`首页 / 分类 / 翼码 / 订单 / 我的`。

- 中央按钮为白色圆形、智慧蓝翼码图标、克制品牌阴影。
- iOS：`56pt`，上浮 `12pt`。
- Android：`64dp`，上浮 `16dp`。
- 微信小程序：`112rpx`，上浮 `24rpx`。
- 中央位置禁止替换为头像、发布、营销或普通扫码。

### 8.2 动态码

- 二维码与条形码并存，默认 `45 秒`更新。
- 码区使用白底，四周留足扫描静区。
- 显示倒计时、动态安全状态、“请勿截图转发”、调亮屏幕和刷新动作。
- 翼码用于身份与权益核验，不等同于支付码。
- 正常、未认证、冻结、过期和核验失败均有图标、文字与颜色三重表达。

### 8.3 数字会员卡

- 使用智慧蓝至深海蓝渐变和低透明度翼纹。
- 显示会员姓名、企业、等级、脱敏编号、认证状态与有效期。
- 资产摘要显示福利余额、餐卡、券和积分，但二维码中不得携带这些明文。
- 企业可拥有次级身份区，不得改变智慧翼主卡结构。

## 9. 跨平台统一规则

原则：**同一品牌、同一业务、平台原生。**

### 9.1 三端必须一致

- 品牌标志、色彩、字体层级、图标语义。
- 五栏导航与中央翼码。
- 会员卡、动态码、资格原因、资产与订单信息结构。
- 文案、状态、金额精度和服务端业务规则。
- 动效时长、品牌语气和隐私边界。

### 9.2 三端允许不同

| 平台       | 原生规则                                                                  |
| ---------- | ------------------------------------------------------------------------- |
| iOS        | 尊重安全区、系统返回手势、动态字体、iOS 控件节奏和触感反馈                |
| Android    | Material 3 触控节奏、系统/预测返回、edge-to-edge、48dp 最小触控和系统触感 |
| 微信小程序 | 动态读取胶囊位置、自定义 TabBar、底部安全区、分包和返回后台刷新翼码       |

禁止在 iOS/Android 绘制微信胶囊；禁止把 iOS 控件外观硬套到 Android；禁止三端使用不同的业务名称和状态逻辑。

## 10. 动效与触感

- 快速反馈 `120ms`：按压、开关、图标状态。
- 标准切换 `200ms`：Tab、卡片展开、局部状态。
- 强调转场 `320ms`：会员卡、翼码弹出、底部弹层。
- 翼码更新使用单圈倒计时，不持续旋转 Logo。
- 成功核验使用一次轻触感；风险/冻结使用明确但不过度的警示触感。
- 尊重“减少动态效果”；关闭动效后不能损失状态信息。

## 11. 文案语气

- 先说结果，再解释原因，再提供动作。
- 使用“你可以购买”“还需完成手机认证”“本月剩余 1 件”等直接文案。
- 不使用“尊贵的您”“智能为您开启幸福”等空洞语言。
- 资格拒绝必须告诉用户原因和下一步，不只显示“无权限”。
- AI 建议必须使用“根据……建议……”的可解释结构。
- 支付与核销不使用模糊成功文案；以后端最终状态为准。

## 12. 无障碍与安全

- 正文和重要图标达到 WCAG AA；智慧蓝配白字对比度约 `5.12:1`。
- iOS 最小触控 `44pt`，Android `48dp`，小程序 `88rpx`。
- 状态不得只靠颜色，必须同时有图标和文字。
- 支持系统字号、读屏、焦点顺序和键盘操作（适用端）。
- 动态二维码提供条形码备选和调亮屏幕。
- 翼码、支付码、手机号、会员编号和消费洞察遵循最小披露。

## 14. 变更治理

- VI 版本使用语义化版本号。
- 色值、标志、字体、翼码结构和导航变化属于主版本变更，需 Owner 书面确认。
- 新组件必须复用既有令牌；禁止新建近似品牌蓝、随意圆角和第四套图标。
- 合作商联合品牌、支付视觉和高风险状态必须经过产品、安全与法务边界核对。
- 每次发布同时检查 iOS、Android、微信小程序三端，不允许单端私自偏离。

## 15. VI 1.0 冻结项

以下内容从 2026-08-13 起冻结为正式基线：

1. W/翼形主标志和 `智慧翼 Smart Wing` 名称。
2. 智慧蓝、深海蓝、夜空蓝为核心品牌色。
3. 品牌主张“让每一份福利，被看见、被理解、被善用”。
4. `首页 / 分类 / 翼码 / 订单 / 我的` 五栏结构。
5. 中央翼码、数字会员卡和 45 秒动态身份码。
6. 三端统一令牌、信息结构与业务，保留各平台原生交互。
7. 智慧翼主品牌—企业身份—合作商履约三级品牌层级。
8. AI 以可解释建议和行动为表达，不建立独立紫色品牌。

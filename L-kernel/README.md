# L-kernel

本次主线候选仅安装 `arch` 星准接线板：按节点与接口选择接通状态，并把请求交还原业务处理者。现有节点、Realm、会员和数据库规则不迁入、不复制，契约板块不改。

未挂载的业务接口不会绕过主板；健康检查、Jobs 与 Runner 和主板并列。连接快照可由各 L 自己的运行层保存和恢复，L-kernel 本身不保存任何节点或公司资料。

生产业务 HTTP 装配缺少 `ArchBoard` 时直接拒绝启动。节点与接口标识在进入主板时统一校验，整板替换先完成校验再一次生效；宿主状态只接受向前推进的 revision，相同开关值不会重复写盘。Release Engine 把 `L-kernel/**` 的变化展开到实际继承它的服务，但不会生成可部署的 L-kernel 服务。

会员、节点等长期内核仍留在各自开发分支，待单独验收后再逐片迁入。

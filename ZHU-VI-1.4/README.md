# zhudatuan 主打团 VI 1.4

`ZHU-VI-1.4` 是 `zhudatuan 主打团` 的 Logo 定稿候选包。

- 版本：`1.4.1`
- 日期：`2026-09-03`
- 设计基线：继承 `ZHU-VI-1.3` 的字体、栅格、留白和界面蓝色体系
- 本次新增：无框皇冠主字标、黑红与蓝色两套同构配色
- 当前状态：Ethan 已确认整体方向；SVG 为工程母版，PNG 为概念确认图

## 核心结构

Logo 以“团中有主”为骨架：

1. 中央“主”表示唯一主轴。
2. 皇冠替代“主”顶部的一点，与主字共用同一主题色。
3. 末横右端的收角是唯一辅助色，承担落印与完成结构的作用。

去除包围式外框后，图形以开放轮廓突出“主”；名称中的“团”由横向标准字完整表达。

## 两套正式配色

### A · 墨黑朱红

- 主色：`#171717`
- 收角：`#E5482D`
- 推荐：品牌封面、发布物、线下物料和强调品牌态度的场景

### B · 主打蓝

- 主色：`#143A8F`
- 收角：`#1F5EFF`
- 页面底色：`#F5F7FA`
- 推荐：商城 H5、管理后台、产品界面和数字化交付

蓝色沿用既有 VI 蓝色 Token，不建立第三套蓝色。

## 使用原则

- 两个版本几何结构必须完全相同，只允许颜色切换。
- 皇冠必须与主字使用同一主色，不使用金色或独立强调色。
- 不拉伸、不旋转、不添加阴影、渐变、描边、发光或立体效果。
- 不把皇冠拆成独立图标，不把右下收角改成箭头。
- 小于 `32px` 时优先使用独立图形标，不使用横向字标。
- 横向字标中的名称只能写作 `主打团`；工程及文档全称使用 `zhudatuan 主打团`。

## 文件性质

- `*.svg`：透明背景的工程母版，可直接用于 Web 与产品界面。
- `*-preview.png`：从横向 SVG 生成的浅底验收预览，不作为透明生产资产。
- SVG 字标仍使用中文字体文本节点；进入商标注册、印刷制版或外部供应商流程前，应在专业设计软件中转曲并进行光学校正。

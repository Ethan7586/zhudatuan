# AU-426｜组织与合作方初始模型

## 范围与方法

- 主审文件：`02_platform_pingtai/database/supabase/migrations/20260821014000_create_organization_partner.sql`。
- 交叉核对：后续组织范围、合作方与门店服务 lifecycle 迁移。
- 本批为静态迁移语义与调用关系审阅；未执行数据库重放或线上操作。

## 运行结论

组织域以单位树和 closure 表表达 platform 至 department 的层级，并通过 source binding 保持旧资源到规范组织节点的一对一映射；assignment 保存有证据、有效期和状态的层级关系。合作方域建模供应商/门店/品牌、协议、资质文档、伙伴关系及门店—组织服务绑定，地址字段以密文/令牌/密钥版本成组约束保存。

后续组织范围、合作方、门店和服务生命周期迁移持续基于这些表写入与校验。两域初始表都启用 RLS。

# AU-362｜Supabase 商业资源与员工资格

`20260812200000_commercial_resources_and_employee_qualification.sql` 建立商业资源图（品牌、门店、供应商—品牌、商城协议、商品池）以及员工资格、城市范围、可见/可购策略和限购模板。跨表租户一致性与选择器由触发器验证；新资源启用 RLS、撤销浏览器表权限，全部资格与商业判断经 service-role RPC。

资格引擎从有效 storefront membership、SKU/商品、上架与协议事实开始，叠加城市、allow/deny 策略和 SKU/商品/类别限购；订单断言以稳定排序的咨询锁覆盖 SKU 与商品级限额，创建订单写入资格证据与授权审计。当前 API 的公共目录与购物车路径仍调用合格目录/购物车 RPC；资格管理入口与数据库契约测试也仍在基线内。后续迁移重定义目录读取、订单创建和资格中心的部分公开函数，但没有移除本文件的商业资源表、资格核心或订单前置逻辑。

结论为 G0：商品资格、限购和商业资源数据边界职责。未发现新增 P0–P3 或删除候选；未执行数据库契约测试、迁移或订单写入。

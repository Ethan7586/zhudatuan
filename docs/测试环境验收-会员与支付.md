## 三、安全与失败场景

| 场景       | 操作                                   | 正确结果                                         |
| ---------- | -------------------------------------- | ------------------------------------------------ |
| 手机未认证 | 用 `buyer002` 登录并尝试结算           | 在创建订单前明确提示“手机尚未验证”，不能支付     |
| 余额不足   | 用 `buyer002` 或余额不足的个人账号结算 | 不能伪造成功；应提示余额不足或外部支付未接入     |
| 无库存     | 选择库存为 0 或数量超过库存            | 购物车/结算页阻止提交                            |
| 不可购买   | 选择显示“不可买”的商品                 | 服务端拒绝加入或下单，并显示原因                 |
| 限购       | 同一限售商品超过允许数量               | 显示限购原因，不能靠刷新绕过                     |
| 重复提交   | 支付过程中不要连续点击；若重复请求     | 只能生成一次有效扣款，不得重复扣余额             |
| 越权订单   | 尝试访问其他账号订单                   | 返回无权限或查无数据，不能看到他人信息           |
| 错误密码   | 故意输错一次后再输正确密码             | 错误时不登录；正确密码可恢复登录。不要连续错五次 |

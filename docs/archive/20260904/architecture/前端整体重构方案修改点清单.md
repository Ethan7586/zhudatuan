## 二、最终依赖方向

所有正式页面统一为：

```text
Route
→ ViewModel
→ Application UseCase
→ Public Port
→ Infrastructure Gateway
→ Typed SDK
→ Commerce API
```

返回方向：

```text
Typed DTO
→ Mapper
→ Immutable Model
→ ViewModel State
→ Pure View
```

硬性规则：

- Route 只读参数、执行 Guard、获取依赖、创建 ViewModel、渲染 View。
- View 不导入 Router、TanStack Query、SDK、Gateway、DTO Schema。
- ViewModel 可以管理 Query、Mutation、URL 状态、Reducer、取消请求和缓存失效，但不返回 JSX。
- Application 不导入 React、Router、TanStack Query、SDK。
- Model 不导入浏览器 API、React、Router、SDK。
- Public 不导入 Query、SDK、Infrastructure，不暴露内部 Model 或 DTO。
- Infrastructure 不导入 View、ViewModel、Route。
- Feature 间只能引用对方 `public/index.ts`。
- 所有依赖在 App 组合根创建，不在页面模块建立全局 Gateway 单例。
- 简单模块可以省略无职责目录，但不能创建空壳。
- 不出现 `Utils`、`Helpers`、`Common`、`Manager`、`BaseService`、`Legacy`、`Compat`、`Fallback`、`V2` 等生产命名。

目标 feature 结构严格采用方案中的结构：

```text
feature/product/
├── public/
├── model/
├── application/
├── infrastructure/
├── viewmodel/
├── view/
├── route/
├── Manifest.ts
└── index.ts
```

## 十二、数据一致性、安全、性能

### 数据一致性

- Query Key 统一包含 `client + scopeKind + scopeId + accessVersion + resourceVersion + resource + filter`。
- Storefront 公共查询使用 `handle + mall + releaseVersion + catalogVersion`。
- Scope、Membership、accessVersion 变化时统一取消旧请求并清缓存。
- 金额、库存、券、余额、订单、退款绝不做最终乐观更新。
- Mutation 成功后精确失效并权威重读。
- `VERSION_CONFLICT` 显示冲突，不覆盖服务端。
- SSE 按 eventId 去重、按 aggregate version 防回退。
- 草稿和选择集可本地保存；秘密、Proof、OTP、密码不得保存。

### 安全

- ViewModel 不自行判断角色，只消费服务端返回的 Permission/Capability。
- 所有写操作携带 CSRF、Idempotency Key、Access Version、Expected Version。
- 高风险操作携带 Action Proof。
- 同一 pending command 双击只提交一次；显式重试复用相同 command identity。
- Gateway 负责安全 Request Context，Application 不依赖 SDK。
- 错误统一经过 `@shop/presentation` 脱敏。
- 上传不 Base64 塞进 JSON。
- 外部跳转由 `NavigationPort` 校验 HTTPS 与白名单。

### 性能

- Route/Feature 保持懒加载。
- Query 支持 AbortSignal，迟到响应不得覆盖新 URL。
- 搜索防抖，下一页预取。
- Session 多 Scope 加载不能对任意 roots 使用无界 `Promise.all`，改为最大并发 4。
- 售后附件上传最大并发 2。
- SSE 只更新受影响 Ticket/Message。
- 表格超过阈值才虚拟化，并保留 `<table>` 语义和键盘导航。
- 删除设备重复页面后重新收紧 bundle budget，不因重构放宽预算。
- ViewModel 使用稳定 selector；actions 使用稳定引用，避免整页渲染。

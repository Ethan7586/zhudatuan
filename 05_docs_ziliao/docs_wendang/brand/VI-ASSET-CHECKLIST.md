# 向甲方索取的 VI 资产清单

## 必需

- Logo 矢量原稿：AI、SVG 或 EPS，至少一种可编辑格式。
- 中文标准字、英文标准字及中英文组合规范。
- 品牌标准色：RGB、HEX、CMYK、Pantone（如有）。
- 深色底、浅色底、单色和反白版本。
- 标志保护区、最小使用尺寸、禁止用法。
- 商标权属主体、允许使用的产品名和授权范围。

## 推荐

- 品牌字体及商业使用授权说明。
- App 图标原稿、公众号头像、企业微信头像。
- 微信分享首图或宣传主视觉源文件。
- 既有官网、公众号、宣传册作为一致性参考。
- 品牌手册 PDF 与最近一次更新时间。

## 收件验收

- 不接受只有聊天截图或低清 JPG 作为唯一源文件。
- 确认图稿中的文字已转曲，或一并提供合法字体。
- 确认透明背景、边缘无白底、颜色空间清晰。
- 记录提供人、提供日期和书面确认渠道。

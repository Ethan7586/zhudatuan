## 1. 状态口径

- `LEGACY_FROZEN`：仍被调用的旧制品；旧版本、旧 checksum 或旧局部形状不参与运行放行。
- `OBSERVATION_ONLY`：只采集或解析结果，结果不改变请求、登录、Worker 启动或服务健康。
- `ZERO_CONSUMER`：当前主轴没有生产调用者，可在新契约池接管后删除。
- `ACTIVE_REAL_SAFETY`：直接防止真实业务损失或串线的约束，不属于旧契约权威。

“是否可能阻断”记录当前真实执行效果；测试或离线审计命令的失败与生产运行阻断分开记录。

## 3. 代码冻结验收

- Identity 5 处、Registration 4 处响应 `.parse()` 已全部退出裁决；Schema 只保留 `safeParse` 观察。
- 登录 Session callback、ticket exchange returnTarget、登录／注册 challenge、注册 authentication callback 增加未知字段的定向回归均通过。
- Auth 请求 Header 明确不含 `x-contract-version`；Storefront 已不发送该 Header，过期测试不再要求它存在。
- `HttpApp` 现有测试覆盖旧版本 `0.0.0` 返回成功并记录遥测；runtime compatibility 现有测试覆盖旧 checksum 不进入健康判定。
- returnTarget 白名单和到期校验、CSRF、Realm/Membership 一致性、ticket 有效期、Worker 节点与数据边界均未移除。

# RV-0073｜发布制品校验清单写入器独立复核

- 基线：`5a1ce71eebbefaa826368a9e1dc17730f9363bc4`；仅静态审阅，未在任何目录创建或改写清单。
- 对象：`04_tools/scripts/release/inventory.mjs` 及唯一内部依赖 `artifacts.mjs`，对应 DC-0095 / GX-0053。

## 入口与行为

- 脚本必须接收显式目标目录，且拒绝 `/`；随后以稳定字典序递归枚举普通文件、计算 SHA-256，并在目标根写入 `checksums.sha256`。
- 枚举器遇到符号链接、设备等非常规项即抛错。写入清单前排除既有 `checksums.sha256` 与 `release.sigstore.json`，避免自散列和将后续签名错误纳入待签清单。
- 未发现 package、workflow、发布配置或仓内源码调用该脚本；但制品目录工具可由人工发布流程或仓外 CI 触发，静态零引用不足以证明无用。阿里云部署资料仍描述 checksum/signature 制品关系。

## 结论

- **GX 维持，不得删除或执行。** 它是制品完整性清单的写入边界；运行会修改指定制品目录，无法在审计分支验证而不改变状态。
- 未验证目标目录是否为隔离制品、清单与签名的实际顺序、外部 CI 调用、文件系统异常处理及发布恢复流程。
- 后续只能在最新主线的独立发布治理批次中，由 Release Owner 在隔离制品目录验证清单、签名、失败恢复与回滚证据；本审计分支不创建制品。

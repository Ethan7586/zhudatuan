# AU-414｜订单付款超时安全回收

## 范围与方法

- 主审文件：`02_platform_pingtai/database/supabase/migrations/20260820127900_payment_expiry_guard.sql`。
- 交叉核对：库存付款到期契约、支付查询守卫契约及微信支付观察状态机。
- 本批为静态调用链与迁移语义审阅；未执行数据库重放、构建或线上操作。

## 运行结论

到期工作者只领取已过期且不再有有效预留的待付款订单，并以 `SKIP LOCKED` 锁定订单。若订单存在任一微信支付尝试，只有支付与尝试均终态、且有不可变终态观察证据时才允许释放库存和取消订单；这避免本地超时误判为未扣款。成功回收后同步取消子订单并留下系统审计记录。入口仅授予 service role，相关契约测试覆盖安全条件和 ACL。

固定基线未发现该 canonical RPC 的仓内作业调用，无法确认生产调度器或仓外 service-role 消费者。

## 审计结论

- DC-0066 / G1：不得删除；先核验生产到期作业、RPC 调用日志、活跃预留与支付对账恢复路径。

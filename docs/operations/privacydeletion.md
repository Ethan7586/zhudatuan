# 隐私删除运行手册

## 触发症状、用户影响与严重级

合法主体删除请求、租户终止、保留期到期或错误采集确认后触发。超期未处理、越权删除、法定保留冲突或删除后仍可从在线系统检索为 P0/P1。该流程不等同于删除订单、支付、账务或审计事实。

## Owner 与前置权限

Privacy Owner 主责，Legal 判定法定保留，Security 复核身份与范围，各数据 Owner 执行。必须有已验证主体、Tenant/Scope、请求依据、数据发现清单、保留/Legal Hold 决定、审批和幂等请求 ID。操作人不得同时批准和执行受限数据删除。

## 只读诊断

生成数据地图：权威表、搜索/报表投影、Redis/会话、对象附件、导出、通知端、Provider 外部副本、审计和备份。按字段分级确定擦除、Token 失联、聚合保留或法定冻结；只输出数量、分类和引用 Hash，不导出待删明文。

## 止血

对确认错误采集停止继续处理和新导出，撤销活动会话、签名 URL 与任务授权快照；对争议请求设置短期处理冻结但不删除证据。存在 Legal Hold 时暂停删除并通知申请人，不绕过保留策略。

## 恢复

用同一请求 ID 执行领域级去标识化：移除直接标识符，搜索字段重新 Tokenize 或删除，保留必要财务事实但断开主体映射；清除缓存和搜索索引；撤销导出与对象版本；向支持删除的 Provider 发送受审计请求。备份不原地改写，在恢复时应用删除账本，且到期后按备份生命周期消除。

## 数据核对

以普通用户、管理员、搜索、报表、导出、对象签名 URL 和 Provider 查询逐层验证不可再识别；确认订单金额、账本平衡、审计 Hash 链与法定凭证仍完整。记录每类处理数量、失败项、外部回执、缓存失效版本和删除账本 Hash。

## 回滚边界

执行前可撤销请求；去标识化和密钥销毁后不可恢复个人映射。误删不得从生产备份原地恢复，应按安全事件评估，在获得 Legal、Privacy 与 Security 批准后只恢复合法最小字段。财务冲正不属于隐私删除。

## 关闭条件

所有在线权威、投影、缓存、搜索、对象、导出和可控 Provider 均完成；备份恢复删除账本已登记；法定保留数据已去标识化并最小化；复核人无法通过批准查询重新识别；审计和申请人通知完成。

## 复盘链接

越权、误删、超期、外部未执行或可重新识别必须建立 `{postmortemUrl}`，记录根因、影响主体、补救、监管/客户通知决定和长期控制。

# Claude 字形锁定补充指令

把本条视为最高优先级，并覆盖上一版提示词中“原创定制中文字形”和“定制英文字形”的要求。

附件 `zhudatuan-wordmark-approved.png` 中的 `zhudatuan 主打团` 已经正式通过。它不是风格参考，而是不可改动的字形母版：必须保留相同的字体、字重、笔画结构、字符宽度、字面比例、字内间距和收笔形态。不要重新绘制、描摹、变形、美化或用近似字体替换，也不要让图像生成模型重新生成这几个字。

优先直接使用同目录的 `zhudatuan-wordmark-outlined.svg` 作为设计图层；它已经转成矢量轮廓，不依赖本机字体。需要可编辑文字或网页复现时，再使用 `zhudatuan-wordmark-reference.html`、`zhudatuan-wordmark-reference.css` 与 `fonts/` 中随附的字体文件。原始像素依据是 `zhudatuan-wordmark-approved.png`。

你现在只设计编排系统，不设计新字形。允许改变的只有：

- `zhudatuan` 与 `主打团` 两个文字组之间的相对位置、组间距与整体比例；
- 横排、上下排、左对齐等组合方式；
- 整体尺寸以及黑、白、深蓝 `#143A8F` 三种单色应用。

不允许改变任何单个字符，不允许增加独立图标、方框、圆框、徽章、底板、装饰线、渐变、阴影或立体效果。

请基于同一套锁定字形制作 6 个真正可比较的编排方案，全部放在干净白底上，不要做 mockup。每个方案都必须能与母版叠加核对字形；差异只能来自组合关系，不能来自字体变化。

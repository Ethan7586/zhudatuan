## Gate 7：基础设施、安全和性能

### 基础设施

合并并删除重复的：

- `infrastructure/aliyun`
- `infrastructure/zhudatuan/aliyun`
- `infrastructure/storefront-compatibility`

最终分层为：

```text
container/
cloud/
network/
monitoring/
backup/
security/
```

生产拓扑：

- Edge/WAF多PoP。
- API跨两个AZ Active/Active，最少2个实例，常态3个。
- Jobs跨AZ Active/Active，使用PostgreSQL Lease和单调Fencing Token。
- PostgreSQL单写Primary、跨AZ同步Standby、Read Replica。
- Redis跨AZ Primary/Replica；丢失时回源，不影响正确性。
- Queue三节点Quorum或同等级托管服务。
- 对象存储私有、版本化、跨区域复制。
- 第二地域Warm Standby。
- Secret Manager/KMS管理所有密钥。

`Caddyfile`、ALB、Kubernetes或容器编排配置只保留一个API上游池，删除Registration、WebBusiness、Purchase独立端口和路由。

四类探针必须分离：

- `live`
- `ready`
- `startup`
- `dependency`

### 安全

- 精确CORS，禁止凭证模式下使用 `*`。
- CSP默认拒绝。
- HSTS、Frame Ancestors、Permissions Policy统一配置。
- URL禁止Token、完整手机号、身份证、Membership ID。
- PII字段级或信封加密。
- PII查看、解密、导出本身写Audit。
- CSV防公式注入。
- 上传校验MIME、大小、Hash并扫描病毒。
- CI使用OIDC短期凭据。
- 生成SBOM、许可报告、制品签名和Provenance。
- Git历史、日志、备份、旧制品进行凭据扫描和撤销确认。

Webhook严格执行：

```text
TLS
→ Content Length
→ Provider Routing
→ Key Version
→ Signature
→ Timestamp
→ Nonce Replay
→ Merchant/App Binding
→ Decrypt
→ Order/Amount/Currency
→ Durable Inbox
→ Fast Ack
→ Async State Machine
```

### 性能门禁

目标必须固化为自动测试：

| 指标                          |    门槛 |
| ----------------------------- | ------: |
| 月度可用性                    | ≥99.95% |
| 缓存命中目录读取p95           |  ≤150ms |
| 普通查询p95                   |  ≤300ms |
| 详情查询p95                   |  ≤500ms |
| 普通命令p95                   |  ≤800ms |
| 原子下单p95                   | ≤1500ms |
| Webhook durable accept p99    |  ≤500ms |
| Outbox 99%延迟                |   ≤30秒 |
| RPO                           |  ≤5分钟 |
| RTO                           | ≤30分钟 |
| 超卖/重复扣款/重复核销/不平账 |       0 |

容量基线：

```text
1000商城
1000万会员
500万商品
2000万SKU
5000 API QPS
300下单TPS
600支付回调TPS
100万单券批次
```

代码级约束：

- Keyset Cursor默认50、最大200。
- 禁止`SELECT *`、N+1、无界聚合、全表Offset。
- SQL配置Row、Byte、Time、Plan Budget。
- 所有实例池总连接数不得超过数据库上限70%。
- 裸 `Promise.all` 禁止处理无界输入。
- Checkout只对独立只读Port执行有界并发，必须有 concurrency、deadline、AbortSignal。
- 批处理必须分块、暂停、恢复、取消、失败项重试。
- 缓存Key包含事实版本。
- 余额、库存、支付状态、核销资格不得以缓存作为命令判断事实。

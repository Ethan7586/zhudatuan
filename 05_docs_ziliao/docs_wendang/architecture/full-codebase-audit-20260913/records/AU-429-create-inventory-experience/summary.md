## 运行结论

库存域建立库存项、预留、流水、观测、幂等命令、同步状态和人工切换复核记录。订单创建调用库存预留，支付结算调用提交；库存命令以 `(scope_id, operation, idempotency_key)` 唯一键承载重复请求边界。

体验域建立应用、版本、发布和领域绑定，并以可延迟的 application head-version 外键支持同一事务内创建版本与更新头版本。后续授权解析通过 application/version 反查 scope，Console 的应用管理操作直接消费该模型。

营销域建立有预算上限的 campaign 和幂等 redemption；应用实现以受限列更新推进 `spent_minor`，并在结算报价中读取有效活动。全部表启用 RLS；后续迁移提供索引与历史数据对账。

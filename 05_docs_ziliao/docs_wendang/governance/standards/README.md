# ZDT 有效标准集

本目录承载由根 [`LAW.md`](../../../../LAW.md) 选择性启用的标准。文件存在不等于生效；精确版本和状态以 LAW 有效标准登记区为准。

| 标准 | 版本 | 唯一职责 | 明确不负责 |
| --- | --- | --- | --- |
| [`YC-GOV`](01-雍彻科技治理标准.md) | `1.0.0` | 标准生命周期、权威边界、责任与单一契约源治理 | SFL、产品、安全实现和运行事实正文 |
| [`SFL-CORE`](02-SFL核心标准.md) | `2.2.0` | 节点、经营线、Realm、Membership、主权承载、四流与历史共同语义 | 安全控制、具体产品、疆域和运行工具 |
| [`SFL-SRI`](03-SFL安全与运行完整性标准.md) | `1.0.0` | 可对应真实损失的身份、写入、交易、制品与恢复完整性 | 业务拓扑、产品功能和具体运行绑定 |
| [`ZDT-BIZ`](04-主打团标准.md) | `1.0.0` | 主打团商城、会员、供应链、交易、售后和财务结果 | 通用 SFL、安全实现、表结构和云资源 |
| [`REALM-GOV`](05-疆域标准.md) | `1.0.0` | 具体疆域的标准版本、标识、本地绑定、例外与 UNKNOWN | 改写上级语义或把运行事实永久化 |

## 引用方向

```text
LAW
└── YC-GOV 1.0.0
    └── SFL-CORE 2.2.0
        ├── SFL-SRI 1.0.0
        ├── ZDT-BIZ 1.0.0
        └── REALM-GOV 1.0.0
            └── 具体疆域文件（须单独说明状态）
```

安全标准保护跨产品结果，业务标准定义主打团结果，疆域标准绑定本地事实；三者通过引用核心语义协作，不互相代写。

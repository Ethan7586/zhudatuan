# AU-345｜Supabase 内部支付、退款与对账

`20260725014000_payment_refund_reconciliation.sql` 强化早期内部账户支付的请求键串行化、账户行锁、账本/支付/分配/订单原子事实；还提供按支付分摊退款的内部退款 RPC 和逐订单支付、分配、账本、退款一致性报告。退款和对账初版均仅授予 `service_role`。

发现 F-0239（P2）：当前 Commerce API 仍在管理员退款与财务对账入口调用 `api_execute_internal_refund` 和 `api_finance_reconciliation`；后续 canonical 迁移分别撤权并删除二者，改为授权包装器，但仓内未找到新包装器的服务调用。这与 F-0238 的售后提交脱节共享发布数据库来源不一致的根因，但影响的是退款与财务对账路径，单列记录。

内部支付原语也已由后续身份保障包装器承接并撤销 raw service-role 权限；本迁移因此仍承担完整历史演进责任，不能按当前原语终态反推为垃圾。未运行迁移、支付、退款或对账查询。

# AU-328｜Supabase Production MVP 数据基座

该首个迁移建立租户/企业/商城、用户与角色、供应商/商品/SKU/库存、账户与不可变账本、购物车、订单/子单/订单项、支付/退款/售后、审计及请求幂等键等基础表、索引和 RLS/service-role RPC 面，并写入 demo 租户和商品基础数据。数据表由后续迁移持续扩展；本文件是重放链的起点而不是可删除的历史副本。

初始目录、账户、订单及内部支付 RPC 都按 tenant/enterprise/mall/user 约束读写，写账本和审计日志由 immutable trigger 保护。订单和支付原始写入函数后来被身份保障迁移从 service-role 撤权，当前只能经资格/手机号保护包装器进入；其并发幂等问题已在 AU-310 的 F-0236 针对模拟资金链记录，未在本基础函数形成新增独立结论。

已逐段人工审阅表、约束、索引、RLS/RPC、订单/支付事务和初始数据。未运行迁移或本地 reset，避免改变数据库状态。未发现新增 P0–P3 问题或删除候选；结论为 G0（基础迁移与重放职责）。

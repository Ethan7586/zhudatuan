## 迁移责任

迁移给 manifest、契约、安装配置、健康原因及激活证据加入格式/大小/哈希/签名约束，要求 base URL 为 HTTPS、secret ref 受限；它将旧 draft 安装转为 disabled，改为按 scope 的 enabled 唯一性，定义可运行安装的状态集合和加载授权，并重建安装/健康/激活历史的 RLS。它还投递 bootstrap `extensionhealth` 作业，登记 enabled/disabled/degraded 事件。

这些结构控制外部代码是否可被调用、在哪个 scope 运行以及凭据引用如何进入运行时，属于安全和恢复边界。

## 当前运行关系

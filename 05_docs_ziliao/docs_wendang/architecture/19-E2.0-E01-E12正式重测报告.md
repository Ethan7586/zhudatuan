## 4. 本轮维修与收口

初始诊断中的 11 个 `UNKNOWN` 主要是正式原始证据、独立 Oracle 或生产等价执行环境缺失，不等于 11 个业务故障。分项修复后，收口为：

- E02 发现并修复了纵向层级相邻性缺口，同步覆盖内核、数据库迁移与合同测试。
- E10 将 H6 加入后的路由验收数量从旧的 7 域名预期对齐为当前 8 域名事实，并补齐 UTF-8 权威哈希稳定性。
- E12 建立了与生产角色所有权和迁移移交一致的 PostgreSQL 17 验收通道。
- E01、E03、E04、E05、E07、E08、E09、E10、E11、E12 补齐了锁定判据、原始证据导出、独立复算、变异探针和符合性声明。
- PostgreSQL 容器启动后的最终监听等待已统一收紧，避免将启动竞态误判为业务失败。
- E01 最终确认最初的 Schema 权限报错来自通用迁移回放的错误所有权上下文，不是生产权限缺口；执行器已改用生产式角色链。

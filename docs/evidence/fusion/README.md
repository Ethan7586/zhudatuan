# 福利商城融合证据

本目录保存 `zhudatuan` 主线融合 `zhudatuan_li` 时产生的机器可核对证据。

- `Baseline20260904.json` 冻结主线、来源仓、权威文档、工作簿和合同计数。
- `Inventory20260904.json` 穷举 Operation、Event、Page、Requirement、视觉状态与主线/LI Operation 处置；`unmappedCapabilities` 必须为零。
- `DatabaseBaseline20260904.json` 只保存本地确定性数据的聚合计数、金额、水位和不变量，不保存业务明细或 Secret。
- `Approval20260904.json` 保存 Approval 修改点的合同、领域不变量与双文档核验证据。
- `AccessOwnership20260904.json` 保存权限中心、角色治理、会话失效和双边所有权转移的合同、体验与不变量证据。
- `Capability20260904.json` 保存能力继承、配额、依赖健康、双版本条件更新、导航失效和九项可发布能力的核验证据。
- `Identity20260904.json` 保存身份域 37 条主线 Operation、六端认证、会话轮换、邀请/微信防重放、成员注册重置和最小身份上下文的核验证据。
- `Organization20260904.json` 保存组织层级、商城完整聚合、目录差异预览、异步 Experience 初始化、全字段重读和跨租户边界的核验证据。
- `Member20260904.json` 保存成员资料、唯一默认地址、收藏失效解释、偏好投影、PII 脱敏、Scope 隔离和邀请归属硬切的核验证据。
- `Qualification20260904.json` 保存资格材料哈希、审查、发布、撤销、到期、只读预览、策略版本和风险驱动商品自动下架的核验证据。
- `Catalog20260904.json` 保存商品、类目、SKU、商品池、投放、依赖水位、逐行发布收据、Runtime 导入硬切和多消费方最小目录端口的核验证据。
- `Pricing20260904.json` 保存价格簿、Offer、规则审批、统一叠加与促销计算、报价分解/水位、冻结 Quote 和缓存失效的核验证据。
- `InventoryDomain20260904.json` 保存库存聚合、可用量公式、确定性预占锁、互斥终态、TTL 过期、只追加账本、来源幂等、Runtime 导入硬切和公共端口边界的核验证据。
- `ExperienceDomain20260904.json` 保存应用与装修聚合、三主题统一 Schema、不可变版本、全依赖发布证据、原子 CDN Head、失败重试、发布读取、缓存防污染和商城向导的核验证据。
- `MarketingDomain20260904.json` 保存活动、优惠、领取规则、预算原子占用、互斥叠加、确认预留、超期释放、退款回补和历史规则快照的核验证据。
- `ReferralDomain20260904.json` 保存首触归因、招募审核、双层收益上限、福利净计佣基数、规则快照、退款冲正、并发结算、审批提现和财务幂等的核验证据。
- `CartDomain20260904.json` 保存游客令牌摘要、会员单次合并、版本条件更新、逐项批量结果、同 SKU 合并、实时报价/库存和失效项保留解释的核验证据。
- `CheckoutDomain20260904.json` 保存并行依赖报价、全量版本快照、一次性确认令牌、固定锁序、原子下单、反向补偿和超时释放的核验证据。
- 后续证据按工作包写入，不覆盖基线文件。
- 证据只能由代码、生成器、数据库核对或测试结果产生，不能手工将未验证功能标记为完成。
- 文件不得包含密码、验证码、Token、卡券 Secret、Provider Secret、完整手机号、地址或生产数据样本。

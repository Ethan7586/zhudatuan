# AU-360｜Supabase 成员权限命令中心

`20260812160000_membership_permission_command_center.sql` 建立成员授权的基础数据契约：权限风险元数据、唯一 Owner 角色、成员范围校验、角色/显式拒绝的有效权限解析、授权版本递增、Owner 保护，以及权限中心和成员权限/状态命令 RPC。Commerce API 的 admin router 真实注册权限中心与成员权限/状态路径；处理器在调用 service-role RPC 前检查权限、二次验证和自改限制。

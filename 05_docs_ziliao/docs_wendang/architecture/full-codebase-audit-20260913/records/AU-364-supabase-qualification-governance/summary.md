# AU-364｜Supabase 资格变更治理

`20260812220000_qualification_governance.sql` 将高影响资格配置变更纳入预览、申请、独立审批和历史回滚链路。预览根据目标范围、员工/SKU 数量、全量选择器、allow/deny 与现有 active 状态确定审批要求和风险；申请锁定版本并以请求人维度的幂等键保存待审记录。审批 RPC 重新验证活跃管理员与 `qualification.approve` 的有效授权、禁止申请人自审、在审批前复查版本，并将过期请求标记为 stale。

审批后的配置写入复用既有受版本和幂等保护的资格配置命令，并保留请求/审批审计；历史快照可作为受权限和 step-up 门控的回滚输入。治理中心、预览、审批、历史、回滚、模拟和员工资格写入都由当前 admin router 注册并通过 service-role RPC 调用。后续 distributor anchor 迁移包装这些公开 RPC，但没有取代本文件的申请、审批、版本及审计数据责任。

结论为 G0：资格变更四眼治理与回滚事实职责。未发现新增 P0–P3 或删除候选；仅作源码、路由注册与迁移顺序核验，未执行审批、回滚、测试或数据库写入。

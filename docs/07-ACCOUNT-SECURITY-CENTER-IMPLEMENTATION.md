# 账号与会员安全中心实现说明

## 本期交付

- 账号密码从演示口令升级为 PBKDF2-SHA256 独立盐值哈希，密码可修改、可重置。
- 25 个分角色验收账号和唯一 Owner 均已建立可变更的真实测试凭证，初始密码为 `123456`。
- 登录会话在数据库登记，可显示设备、下线单个设备或下线其他全部设备。
- 修改密码、重置密码、变更手机号后，旧会话按安全策略立即失效。
- 手机号只保存不可逆查询标识、脱敏展示值和加密密文；测试账号可在首次使用时绑定手机号。
- 员工商城与管理后台均提供账号安全入口；登录页提供忘记密码流程。
- 管理后台二次验证优先验证当前真实密码，已建立真实凭证后不会退回演示口令。

## 安全边界

- Owner 仍只有 `member-test-owner` 一人；安全中心不会授予、复制或变更 Owner 权限。
- 测试用户名仅在 `APP_ENV=test` 且 `AUTH_MODE=test` 时可用。生产模式支持已注册的 `local_username`、已绑定的手机号以及后续接入的企业身份提供方。
- 修改密码必须校验当前密码，新密码至少 10 位并同时包含字母和数字，且不能与当前密码相同。
- 找回密码会撤销该账号全部会话；主动改密和换手机会保留当前设备、撤销其他设备。
- 验证码 5 分钟有效，限制单手机号和单来源的发送频率，错误尝试累计 5 次后失效。
- 改过密码的测试账号不会再被旧的 `123456` 演示口令兜底登录。

## 服务端接口

| 接口                                       | 用途                           | 是否需要登录         |
| ------------------------------------------ | ------------------------------ | -------------------- |
| `POST /api/v1/auth/credential/discover`    | 登录页确认真实凭证及会员入口   | 否，受登录限流保护   |
| `GET /api/v1/auth/security-center`         | 查询密码、脱敏手机和有效会话   | 是                   |
| `POST /api/v1/auth/password/change`        | 校验当前密码并修改密码         | 是                   |
| `POST /api/v1/auth/security/otp`           | 申请找回密码或换手机验证码     | 否，受验证码限流保护 |
| `POST /api/v1/auth/password/reset`         | 验证手机验证码并重置密码       | 否                   |
| `POST /api/v1/auth/phone/change`           | 校验当前密码与验证码后换绑手机 | 是                   |
| `DELETE /api/v1/auth/sessions/:id`         | 强制下线指定设备               | 是                   |
| `POST /api/v1/auth/sessions/revoke-others` | 下线其他全部设备               | 是                   |

## 上线前仍需完成

当前开发/测试环境会在页面显示调试验证码。生产环境会严格返回 `SMS_PROVIDER_NOT_CONFIGURED`，不会泄漏验证码，也不会假装发送成功。正式上线前必须接入经过备案的短信服务商，并补齐短信模板、签名、发送回执和失败重试监控。

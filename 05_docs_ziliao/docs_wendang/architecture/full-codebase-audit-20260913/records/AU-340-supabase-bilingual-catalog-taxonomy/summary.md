# AU-340｜Supabase 双语商品 taxonomy 基座

`20260725009000_bilingual_catalog_taxonomy.sql` 为商品增加来源/中文展示文本、翻译状态与置信度、三级 taxonomy、分类状态与置信度，并为状态和数值建立数据库约束及审阅索引。它保留来源英文/原文到 `name_en`、`subtitle_en` 的历史投影，只对测试商品执行关键字机器分类；未识别项显式进入低置信度 `welfare_review`，而不是假装已人工确认。

后续治理和严格 taxonomy 迁移把这些字段接入审阅、合法路径校验和目录可见性条件。本文件不注册直接 API/Worker，也不自行翻译或发布商品，归 G0（数据模型及历史分类迁移职责）。

未发现新增 P0–P3 或删除候选。未运行数据迁移，避免改写历史商品字段。

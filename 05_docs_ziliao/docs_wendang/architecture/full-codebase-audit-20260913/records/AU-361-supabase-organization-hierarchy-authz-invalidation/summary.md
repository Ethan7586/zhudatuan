# AU-361｜Supabase 组织层级与授权失效

`20260812170000_organization_hierarchy_and_authz_invalidation.sql` 创建组织单元与闭包表，以父级校验、事务咨询锁和闭包重建维护平台—租户—企业—商城—部门层级；同时将订单、售后和商品资源范围 RPC 扩展为服务器导出的组织路径。Commerce API 的 `loadResourceScope` 使用这些 RPC，而订单、退款和模拟支付路由据此作资源范围授权；客户端不提供目标资源范围。

迁移还将角色权限变更连接到受影响成员的 `authz_version` 递增，配合成员角色/范围/拒绝覆盖的既有触发器使已签发会话的授权投影可失效。后续 distributor 规范迁移重定义范围路径函数以处理实际 distributor 绑定，但保留本文件的组织表、闭包、资源范围与版本失效前置责任。

结论为 G0：组织范围与授权失效基础职责。未发现新增 P0–P3 或删除候选；仅完成源码/注册关系审阅，未执行数据库、测试或线上状态检查。

# AU-317｜Compatibility 成员运营中心

成员运营中心提供受权限分隔的会员投影、邀请码、管理员建档、资料维护和最多 500 行的导入结果。邀请码与建档固定创建 storefront/employee 身份，不能创建管理员或 Owner；初始口令仅以哈希传入数据库、强制首次修改，导入错误报告也主动剔除明文口令。读模型和导入事实表均只经 service-role RPC 使用，PII、历史和导入错误按独立权限选择性投影。

发现 F-0237（P2）：成员资料修改端点授权时使用当前操作人的商城范围，但没有读取目标 membership 的资源范围；对应数据库 RPC 也仅以租户和企业查找目标，而不要求目标商城等于当前商城或操作人 scope。具备 `member.update` 的商城范围管理员若已获得同企业另一商城会员 ID，可能改写其姓名、邮箱或部门。该结论需要独立复核。

除 F-0237 外，未发现新增 P0/P1 或删除候选。审计工作树缺少 Vitest 依赖，未执行测试；现有路由测试覆盖读权限、PII/历史裁剪、重新验证、初始口令哈希和导入错误脱敏。

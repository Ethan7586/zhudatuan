# AU-381｜Supabase 购物车分类投影

`20260815170000_cart_taxonomy_projection.sql` 在认证购物车投影中加入一级至三级 taxonomy 与 category code，同时继续由数据库资格判定提供可购买标识、价格、可用库存和商品事实。`commerce-api` 的购物车路由直接调用此 RPC；Storefront 映射层只接受完整的严格 taxonomy 路径，异常路径回退到既有分类映射，而不由供应商标签决定公开分类。

该函数随后被库存单一事实源迁移重定义，以库存域函数替换早期直接库存表投影。原迁移仍保留购物车 API 演进顺序和字段契约，归 G0，不能因当前函数体已替换而删除。

未发现新增 P0–P3 或删除候选；未执行购物车、库存、测试或数据库写入。

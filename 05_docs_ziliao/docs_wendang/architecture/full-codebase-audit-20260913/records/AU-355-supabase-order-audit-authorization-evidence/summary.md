# AU-355｜Supabase 订单授权审计证据

`20260810150000_order_audit_authorization_evidence.sql` 以事务包装订单创建和内部账户支付原语，在保留其既有订单/支付事实后，为同一 membership、授权证据和请求键追加一次授权审计记录。审计插入按资源、动作和请求键去重，避免正常幂等重放重复产生授权事实；两个包装器仅授予 `service_role`。

当前 Commerce API 的内部支付走 `api_pay_internal_authorized`，订单创建则走该包装器的后续身份保障版本。后续迁移将成员匹配、权限、会话保障和资格检查前置到同一包装链；本迁移是现行审计语义的历史根，归 G0。

未发现新增 P0–P3 或删除候选。未运行订单、支付、审计写入或迁移。

# 账号密码注册与未来身份绑定

## 本期范围

本期先开放“账号 + 密码”注册，手机短信注册暂时保持关闭。新用户需要填写登录账号、真实姓名、企业邀请码和密码。

- 登录账号全局唯一，不区分大小写，4–32 位，必须以字母开头，可含数字、点、横线和下划线。
- 密码使用 PBKDF2-SHA256 独立盐值哈希，不保存明文；至少 10 位，并同时包含字母和数字。
- 必须使用有效的企业员工邀请码。手机号定向邀请码不能用于无手机注册。
- 自助注册只能创建 `storefront` 普通员工会员，权限范围只能是用户本人。
- 管理员、客服、运营、商家及 Owner 不能通过自助注册获得，必须由后台授权。

## 统一会员身份

注册创建的是唯一 `Member`，登录账号只是该会员的第一个身份别名：

```text
Member
├─ local_username  账号（本期开放）
├─ local_phone     手机号（短信服务开通后绑定）
├─ wechat          微信 OpenID/UnionID（后续）
└─ wecom           企业微信身份（后续）
```

未来绑定手机或微信时，应向 `member_login_aliases` 追加别名，不得新建另一个 Member。这样同一人的会员关系、福利账户、订单、权限与审计历史不会被拆散。

## 安全与审计

- 默认生产开关为 `USERNAME_REGISTRATION_ENABLED=false`，发布前需显式打开。
- 注册按可信客户端 IP 计数，每小时最多 10 次；成功注册也保留计数，防止邀请码被批量滥用。
- 保留账号、已有账号及测试账号别名不可注册。
- 注册成功写入 `member.self_registered` 审计记录，保留来源摘要、协议版本和绑定状态，不记录明文密码。
- 未绑定手机前无法自助找回密码，也不能提交订单或付款；页面与服务端均已强制执行。

## 接口与发布

- 注册：`POST /api/v1/auth/register/username`
- 登录：原有密码登录接口同时支持 `local_username` 和已绑定的 `local_phone`
- 生产迁移：`database/supabase/migrations/20260812250000_username_password_registration.sql`

本期不启用真实短信、微信或企业微信 OAuth。启用这些能力时，需同时补充绑定冲突处理、身份合并、解绑二次验证和审计流程。

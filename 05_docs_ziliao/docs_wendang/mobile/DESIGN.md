# 智慧翼统一移动产品设计系统

> 产品路线决议（2026-08-13）：智慧翼采用 iOS、Android、微信小程序统一移动方案；“翼码”是会员身份、福利资产、实体券、消费洞察与行动建议的核心入口。当前优先交付微信小程序，未来正式 iOS/Android 客户端复用同一业务、接口、信息结构与 VI，并保持平台原生交互。既有两套 Android 原型降级为历史参考，不再平行扩建。移动 H5 仅承担分享落地、兼容访问等辅助场景。

跨 iOS、Android、微信小程序的品牌、颜色、字体、图标、翼码与平台映射以 [`智慧翼统一 VI 1.0`](../brand/SMART-WING-UNIFIED-VI-1.0.md) 为唯一上位规范。本文件补充统一移动产品与微信小程序首发规则。

小程序沿用现有智慧翼 VI，不另起一套“餐饮金色风格”。

## 品牌层级

1. `智慧翼 Smart Wing` 是产品主品牌，负责账号、会员、福利账户、资格、订单与售后体验。
2. 企业名称与当前福利商城是第二层身份，例如“示范企业 · 员工福利商城”。
3. 麦德龙、沃尔玛、山姆会员商店、大润发、永辉等是合作渠道或履约来源，只出现在渠道筛选、商品来源、门店、配送与售后信息里。
4. 未取得书面授权前，不描摹或生成合作商标 Logo，不使用对方专属色支配页面；原型使用文字标签和中性占位图，并标注“演示数据”。
5. 移动客户端不直接保存或调用合作商超密钥。所有外部商品、库存、价格、订单和退款接入统一经过智慧翼服务端。

## 核心导航

唯一标准五栏：`首页 / 分类 / 翼码 / 订单 / 我的`。

- `翼码`位于中央，使用智慧翼蓝色二维码图标、白色圆形承载、浅凹槽与克制阴影，是唯一允许高于底栏的品牌级入口。
- 中央入口必须是“翼码”，禁止替换为头像、营销按钮、发布按钮或普通扫码。
- 购物车不占底栏；它是常驻的全局交易入口。首页、分类、搜索/商品列表和商品详情等所有“逛商品”页面右上角必须显示同一款线框购物车，并保留数量角标。
- 商品详情同时保留底部迷你购物车、`加入购物车`与`立即购买`；购物车、确认订单、收银台和支付结果页不重复显示右上角购物车入口。
- 购物车图标统一使用墨蓝细线、双轮、珊瑚红数字角标；不得因平台或页面自行换样式。微信小程序中应避让右上角系统胶囊。
- 微信小程序预留右上角胶囊区域；自定义导航不得与胶囊重叠。
- 待付款和卡券角标保持克制，只有数字大于 0 才显示。

## 首页信息顺序

1. 当前企业、商城、城市与配送地址。
2. 搜索框与扫码入口。
3. 福利卡余额、餐卡余额、优惠券和积分摘要。
4. 运营主视觉，但保持智慧翼蓝色主导。
5. 合作商超入口：全部、麦德龙、沃尔玛、山姆、大润发、永辉。
6. 城市专区、企业专享、员工特惠、即时零售。
7. “到店出示翼码”快捷提示、推荐商品与最近购买。

## 翼码中心

翼码不是单一二维码，而是五层个人福利中心：

1. **动态身份码**：二维码与条形码由服务端签名，默认 45 秒更新；进入后台、冻结账号或会员权限版本变化时立即失效。
2. **会员身份**：会员姓名、企业、部门、会员等级、脱敏会员号、认证状态和有效期。
3. **福利资产**：福利余额、餐卡余额、积分、实体券与电子券；金额与可用状态以服务端为准。
4. **AI 消费洞察**：剩余额度、消费结构、常购品类、累计节省、到期券和年度福利报告。
5. **行动中心**：使用即将到期券、按额度生成采购清单、再次购买、查看附近核销门店和进入组合支付。

隐私与安全边界：

- 翼码用于身份与权益核验，不直接等同于支付码；付款必须由本人再次确认。
- 二维码只携带短时、不透明、可撤销凭证，不写姓名、手机号、余额、企业信息或消费记录。
- 合作商核验端只能获得本次履约所需的最小信息，不能读取会员消费习惯和完整资产。
- AI 只能解释与建议，不得自行付款、修改额度、放宽资格或替会员做高风险决定。
- AI 推荐结果必须再次通过商品可见、可买、城市、企业、员工标签和限售规则。

## 业务表达

- 每个商品必须能显示：来源商超、履约门店或供应商、库存更新时间、配送方式、预计送达、售后责任方。
- “不可买”必须说明原因，例如手机未认证、城市不符、员工标签不符、福利计划不适用或超出限售额度。
- 结算同时支持福利卡、餐卡、优惠券、积分和微信支付的设计占位；未完成真实渠道联调时必须显示“演示/待接入”，不能伪装已开通。
- 山姆等可能涉及会员资格的渠道，必须把“智慧翼会员身份”和“渠道会员资格”分开显示，不能默认互通。
- 不做客户端价格裁决；最终价格、库存、资格和可支付金额以智慧翼服务端结算预览为准。

## 参考图可借鉴与禁止项

可借鉴：沉浸式活动主图、左右分栏分类、中央翼码、订单标签、个人资产卡片、实体券质感和空状态。

禁止照搬：餐饮品牌名称与素材、土金主色、书法字体、中央头像、无法识别的食材图标、静态不轮换的二维码，以及把合作商超伪装成已完成真实接入。

## 响应与状态

- 首屏优先展示骨架屏，不显示整页空白等待。
- 商品、会员、订单各自独立加载，失败时允许局部重试。
- 必须提供：加载、空、离线、超时、无库存、接口同步中、接口降级、未登录、会话失效、未认证手机、资格不符。
- 图片失败使用本地品牌占位图，不能出现破图图标。

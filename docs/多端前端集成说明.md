# 智慧翼企业福利商城多端前端集成说明

技术服务方：雍彻科技（SGSYEN TECH）

## 1. 本次集成范围

本次将桌面端、13/14 寸笔记本端、平板端、微信小程序视觉端和 Android 视觉端统一放入现有生产型 MVP 工程。原有 Supabase、登录会话、商品目录、订单、支付、账户流水及售后接口保持不变。

| 终端           | 访问路径        | 当前定位                                            |
| -------------- | --------------- | --------------------------------------------------- |
| PC Web         | `/`             | 生产型 MVP 主入口                                   |
| 13/14 寸笔记本 | `/laptop-web`   | 紧凑型 Web 界面，已接统一商品、订单与内部账户结算   |
| 平板           | `/tablet-app`   | 横屏/竖屏适配，已接统一商品、订单与内部账户结算     |
| 微信小程序     | `/mini-program` | 高保真 Web 客户端，已接统一商品、订单与内部账户结算 |
| Android        | `/android-app`  | 高保真 Web 客户端，已接统一商品、订单与内部账户结算 |

## 2. 代码组织

- `src/screens`：现有 PC 生产型业务页面。
- `src/features/miniprogram`：微信小程序页面。
- `src/features/android`：Android 页面。
- `src/features/tablet`：平板页面。
- `src/components/laptop`：13/14 寸笔记本页面与框架。
- `src/components/mobile`：移动端、平板端公共外壳、导航及待接入提示。
- `src/adapters/frontendData.ts`：新前端字段与现有生产数据模型之间的兼容层。
- `src/context/MallContext.tsx`：统一终端切换、页面状态及现有商城业务状态。

## 3. 数据和接口边界

1. 五个 Web 入口共享同一生产商品目录、用户账户、订单列表和服务端权限范围。
2. 笔记本、平板、小程序视觉端和 Android 视觉端的内部福利账户结算，统一调用服务端创建订单和账户支付接口；服务端继续执行身份校验、幂等控制、库存校验、余额校验、PII 加密和审计。
3. 多端订单页读取生产订单接口，不再使用固定订单作为登录后的业务结果。
4. 购物车和地址仍属于设备本地会话状态，后续如需跨设备续购，应增加服务端购物车与地址簿接口。
5. 微信授权、微信支付、Android 生物识别、原生消息推送、离线卡包等平台能力尚未接入真实 SDK，点击时显示“接口待接入”，不得当作已完成能力对外验收。
6. 当前小程序与 Android 是可联调的 Web 客户端，不等于已经获得微信小程序包或 Android APK。

## 4. 已完成验证

- TypeScript 全量类型检查通过。
- 18 项自动化测试通过。
- 五个入口生产构建通过。
- `/`、`/laptop-web`、`/tablet-app`、`/mini-program`、`/android-app` 均通过直接访问检查并返回成功状态。
- 生产订单服务保留幂等、权限、库存、余额、加密和审计保护。

## 5. 维护原则

- 不在终端页面中直接访问 Supabase 管理密钥。
- 不复制订单、余额和支付逻辑到前端。
- 所有资金和订单状态以服务端结果为准。
- 新增终端只增加界面适配层，不另建一套业务数据源。
- 演示能力与真实能力必须有清晰标识，避免甲方误判项目完成度。

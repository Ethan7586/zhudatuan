# AU-395｜管理端订单行数修订

`20260819123000_admin_order_line_count.sql` 以不可变迁移方式重定义订单分页和导出读取器，将不同商品行数 `lineCount` 与商品件数 `itemCount` 分开投影，避免多件同 SKU 或多 SKU 订单的两个概念混淆。它保留 AU-390/391 已审的范围过滤、稳定排序和导出上限。

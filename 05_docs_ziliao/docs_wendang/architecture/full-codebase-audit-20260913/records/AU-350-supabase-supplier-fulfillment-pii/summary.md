# AU-350｜Supabase 供应商履约 PII 边界

`20260809094000_supplier_fulfillment_pii_boundary.sql` 为每个子订单复制父订单的加密收件人快照，回填已有子订单并设为非空；触发器确保后续子订单不能缺失同商城父订单的收件人快照。它避免供应商为履约读取包含其他供应商商品的父订单，并提供按 tenant、供应商和子订单精确过滤的 service-role 履约读取 RPC。

固定基线未发现仓内供应商路由调用 `api_supplier_fulfillment`；函数仍是唯一明示的最小供应商 PII 读取形状，且潜在外部履约方未排除。因此新增 DC-0050/G1，而非将其删除或认定为无责任。收件人快照触发器、回填和非空约束为 G0。

未发现新增 P0–P3。未读取任何收件人数据或运行迁移。

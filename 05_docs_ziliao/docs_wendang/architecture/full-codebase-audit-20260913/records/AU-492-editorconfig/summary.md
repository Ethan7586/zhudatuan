# AU-492｜编辑器格式约定深审

- 审阅对象：仓库根 `.editorconfig`（15 行）。
- 方法：人工审阅全部通用与 Markdown/YAML override，并静态检索仓内显式消费者。未修改文件、未运行格式化或 CI。

## 结论

- **G0**：这是被 EditorConfig 兼容编辑器自动解析的仓库级开发约定，不是零运行引用即可删除的普通文件。
- 它统一 UTF-8、LF、末尾换行、两空格和尾随空白；Markdown 保留尾随空白以允许硬换行，YAML 显式保留两空格。该例外与文档/配置语义一致。
- 仓内仅命名审计脚本显式列出该文件；未找到格式化工具直接读取它。外部编辑器/IDE 自动消费和跨平台换行稳定性尚未验证，但不构成删除依据。未发现 P0–P3。

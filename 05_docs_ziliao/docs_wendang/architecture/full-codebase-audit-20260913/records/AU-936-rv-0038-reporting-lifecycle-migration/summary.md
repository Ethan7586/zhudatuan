## 迁移责任

迁移为每个历史 export 生成授权快照并将旧 completed 导出失效；新的 completed 状态必须同时有对象引用、哈希、大小、clean 扫描状态、生成时间及到期时间。它建立 projectionevent 去重事实、scope 索引与 RLS，重写统一资源 scope 解析，并把导出 API 纳入权限/能力契约。

该迁移决定已有导出对象是否还能被访问，也定义事件投影重放的去重边界；不是可被同类报表文件取代的历史杂项。

## 当前运行关系

`ProjectionJobProcessor` 从正式 `projection` 作业读取 event ID，在事务中领取事件并更新投影；`ExportJobRunner` 是正式 `export` 作业处理器。报表 API 读取导出时按请求 scope 查询，并且仅在 completed、对象引用存在且扫描状态 clean 时继续处理；Dashboard 读取 scope 水位来形成缓存版本。模块清单和应用 Job 注册都声明这两个运行入口。

## 裁决与未知项

维持 GX。已静态确认导出访问条件、投影去重和当前 Worker/API 链路仍依赖目标结构；未验证历史对象失效、授权快照内容、跨 scope 过滤、事件重放、水位、过期删除、对象扫描或备份恢复。后续变更须从届时最新主线建立独立报表/数据库专项；本审计分支未访问报表或对象存储。

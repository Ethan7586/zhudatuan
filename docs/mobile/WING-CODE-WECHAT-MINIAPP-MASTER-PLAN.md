# 智慧翼微信小程序与翼码中心主方案

状态：**统一移动方案的微信小程序首发实施计划**  
生效日期：2026-08-13  
产品代号：**翼码**

## 1. 产品决议

智慧翼未来采用 iOS、Android、微信小程序统一移动方案，不再同时维护多个产品方向。当前优先交付微信小程序，未来正式 iOS/Android 客户端复用同一业务、接口、信息结构、翼码和 VI；现有 Android 原型、餐饮会员小程序参考和移动 H5 均不再拥有产品路线决定权：

- 微信小程序：第一交付载体、首期主交易入口和主会员入口。
- iOS/Android：未来正式原生客户端，遵守统一 VI 和业务合同，按平台原生方式重新建设。
- 移动 H5：分享落地、兼容访问和必要的外部跳转。
- 既有 Android 原型：历史参考，停止独立扩建，不能直接作为未来正式 Android 客户端。
- 运营后台：继续负责会员、权限、资格、券、规则、审计和风险控制。

核心产品公式：

> 翼码 = 会员身份 + 福利资产 + 实体/电子券 + AI 消费管家 + 场景行动中心

## 2. 用户体验主轴

小程序底部固定为：

`首页 / 分类 / 翼码 / 订单 / 我的`

翼码采用中央悬浮入口，是智慧翼唯一的移动端超级入口。购物车放在首页、分类和商品页右上角，不挤占底栏。

核心闭环：

`微信进入 → 绑定智慧翼会员 → 发现福利 → 资格判断 → 领取/购买 → 合作商履约 → 翼码核验 → 资产与消费沉淀 → AI 建议 → 再次行动`

## 3. 翼码信息架构

### 3.1 动态身份码

- 二维码与条形码并存。
- 默认 45 秒更新。
- 页面退到后台后立即刷新或失效。
- 支持调亮屏幕、手动刷新、主动冻结。
- 显示最近核验记录与异常设备提示。
- 正常、未认证、冻结、过期、离线不可用五种状态。

### 3.2 数字会员卡

- 姓名、企业、部门、会员等级。
- 脱敏会员号、手机认证、有效期。
- 福利余额、餐卡余额、卡券和积分。
- 适用企业、城市、渠道和限售说明。

### 3.3 实体券与电子券

- 可用、即将到期、已使用、已过期、已冻结。
- 展示券面、适用门店、使用条件、有效期和核销记录。
- 对接线下实体券时保留来源批次、券号映射、导入记录和异常处理。
- 商家核销只读取本次券与资格所需的最小数据。

### 3.4 AI 消费洞察

- 本月额度使用和剩余预算。
- 餐饮、家庭、办公、健康等消费结构。
- 常购商品、常用合作商与常去门店。
- 累计节省金额与年度福利价值。
- 即将到期的券与可能浪费的福利额度。
- 异常消费只做提示，不能未经确认自动拦截正常会员。

### 3.5 AI 行动建议

- 一键使用即将到期券。
- 按剩余额度生成采购清单。
- 再买一次常购商品。
- 查看附近可核销门店。
- 生成节日、家庭、办公或健康采购方案。
- 进入福利余额与个人支付组合结算。

AI 不拥有付款权、改资格权、改额度权和审批权；每个行动都必须由会员确认并重新通过服务端资格校验。

## 4. 技术边界

### 4.1 新增客户端

在现有单体仓库新增 `apps/wechat-miniapp`，采用微信原生小程序 + TypeScript：

```text
apps/wechat-miniapp/
├─ pages/home
├─ pages/category
├─ pages/wing-code
├─ pages/orders
├─ pages/profile
├─ subpackages/product
├─ subpackages/cart
├─ subpackages/checkout
├─ subpackages/vouchers
├─ subpackages/ai-insights
├─ subpackages/security
├─ custom-tab-bar
├─ components
├─ services
├─ store
└─ assets
```

不采用 Android 转码，不使用 WebView 套网页，不让小程序直接连接 Supabase，也不在客户端保存合作商密钥。

### 4.2 复用现有能力

复用智慧翼现有 BFF 的：

- 会员与权限上下文。
- `authzVersion` 即时失效机制。
- 商品、首页、购物车、地址、账户、订单和售后。
- 手机认证与支付资格。
- 企业、城市、员工标签、可见/可买和限售规则。
- 智慧翼 VI 与共享接口合同。

### 4.3 必须新增的服务端能力

```text
POST /api/v1/auth/wechat/session
POST /api/v1/auth/wechat/bind
POST /api/v1/auth/wechat/phone

GET  /api/v1/member-card
POST /api/v1/member-code/challenge
POST /api/v1/member-code/refresh
POST /api/v1/member-code/freeze
POST /api/v1/member-code/verify

GET  /api/v1/vouchers
POST /api/v1/vouchers/{id}/present
GET  /api/v1/ai/consumption-insights

POST /api/v1/orders/{id}/payments/wechat/prepay
POST /api/v1/payments/wechat/notify
GET  /api/v1/orders/{id}/payment-status
```

现有浏览器使用 Host-only HttpOnly Cookie；微信小程序必须使用独立的短期访问令牌。令牌仍绑定唯一会员身份、会话 ID、设备信息、到期时间和 `authzVersion`，不能信任客户端传入的会员、权限和数据范围。

## 5. 微信身份绑定

1. 小程序调用 `wx.login` 获取一次性 code。
2. 智慧翼服务端调用微信 `code2Session`，OpenID 和 session_key 不返回客户端。
3. 用户用现有智慧翼账号、企业邀请码或已认证手机号完成一次身份确认。
4. 服务端把微信 OpenID 绑定到现有会员，不重复创建会员资产。
5. 同一微信身份切换企业会员时必须由服务端返回可用主体，并重新签发单主体会话。
6. Owner 和管理员不能通过微信自助注册获得，只能由后台授予。

## 6. 动态码安全模型

二维码只包含短期随机挑战凭证，数据库保存其摘要与状态：

- 绑定会员、企业、用途、签发时间、到期时间和一次性随机数。
- 默认 45 秒有效；成功核验后立即消费。
- 截图在短时间内也不能重复使用。
- 会员停用、离职、冻结、切换主体或权限版本变化后立即拒绝。
- 核验端需要登录、授权、设备与门店范围校验。
- 每次签发、展示、核验、拒绝和冻结进入审计记录。
- 码内不出现姓名、手机号、余额、企业名称、消费记录或券明文。

会员码用于身份和权益核验，不等同于支付码。支付仍需本人确认。

## 7. 合作商核验端

翼码要形成闭环，必须同步提供合作商核验端，可先做受权限控制的移动网页，后续再做合作商小程序：

- 扫一扫并提交动态挑战。
- 只显示会员是否有本次权益、可核销券和必要的脱敏信息。
- 不显示完整消费历史和其他资产。
- 绑定合作商、门店、员工身份和设备。
- 防重复核销，异常时允许查询审计编号。
- 支持撤销、冲正和离线失败提示，不做无审计的人工改状态。

## 8. 微信组合支付

支付只能在服务端完成金额裁决：

1. 创建智慧翼订单并锁定价格、库存和资格。
2. 预占福利余额、餐卡、券和积分。
3. 计算个人应付差额。
4. 服务端向微信支付申请 `prepay_id`。
5. 小程序调用 `wx.requestPayment`。
6. 服务端验签处理微信异步通知，并主动查单兜底。
7. 支付成功后确认福利扣减和订单状态。
8. 失败或超时释放预占；退款按原支付渠道退回并完成对账。

前端成功回调不能作为到账凭据。金额统一使用分单位整数；客户端不能自行扣余额、改订单或生成支付签名。

## 9. AI 与隐私

- 消费洞察默认只给会员本人。
- 企业管理员只读取合法授权的汇总指标，不查看个人明细。
- 合作商不能获得跨渠道消费画像。
- 每一条 AI 建议标明依据、时间范围和可执行动作。
- 允许会员关闭个性化分析、清除非账务性画像并导出自己的数据摘要。
- 订单、支付、退款和法定审计记录不因关闭 AI 而删除。
- 敏感数据不发送给未签订数据处理协议的模型服务。

## 10. 开发阶段

### 第一阶段：翼码可运行原型

- 新建原生微信小程序工程。
- 接入 VI、自定义底栏和中央翼码。
- 微信登录与现有会员绑定。
- 数字会员卡、动态二维码、条形码和状态页。
- 首页、商品、购物车、订单调用现有接口。

### 第二阶段：权益闭环

- 实体券与电子券钱包。
- 合作商核验端。
- 券核销、防重放、撤销与审计。
- 消费数据聚合和基础洞察。

### 第三阶段：AI 与支付

- AI 消费洞察与行动建议。
- 额度规划、到期提醒和年度福利报告。
- 微信支付、组合支付、退款和对账。
- 订阅消息、发货管理和小程序审核发布。

## 11. 验收底线

- 管理员停用会员后，翼码与小程序会话立即失效。
- 截图二维码不能在到期或核验后复用。
- 手机未认证用户可看权益但不能进入需要个人付款的流程。
- AI 推荐不能展示或购买资格范围外商品。
- 合作商核验端看不到会员完整消费画像。
- 支付结果只以后端回调或查单为准。
- 退款、冲正、余额释放和核销撤销全部可审计。
- 小程序不包含 AppSecret、微信支付私钥、API v3 密钥或合作商密钥。

# 智慧翼企业福利商城——正式上线验收清单

本清单用于决定商城能否从生产型 MVP 进入正式生产环境。每项须记录验收人、日期、证据链接和回滚负责人。

## A. 商品与履约

- [ ] 已导入正式 SPU、SKU、主图、规格、税率、可售范围、福利账户适用范围及售后规则。
- [ ] 商品分类经过业务负责人抽检；无“测试商品”“待完善”“模拟数据”对外可见。
- [ ] 至少一家供应商完成商品、库存、下单、发货、退款的沙箱与生产联调。
- [ ] 库存不足、价格变化、供应商超时、重复回调与部分发货均有可验证的处理结果。
- [ ] 虚拟商品具备发码、核销、补发、撤销、有效期和异常处理规则。

## B. 身份、权限与隐私

- [ ] 企业 SSO、手机号认证或微信身份方案已完成签名校验与账号绑定；阶段访问码已关闭。
- [ ] 企业、部门、员工在职状态和角色由权威来源同步，并完成离职/调岗回收权限验证。
- [ ] 员工只能访问本人订单、账户和售后；管理员权限经过最小权限复核。
- [ ] 收货信息加密密钥已配置在托管密钥库，并完成密钥轮换与解密授权演练。
- [ ] 日志、分析和客服导出不包含完整手机号、地址、cookie、访问码或支付凭据。

## C. 交易、支付与财务

- [ ] 创建订单、内部支付、退款均完成并发、重试、超时和相同幂等键不同请求测试。
- [ ] 订单金额、支付分摊、账户流水、退款与对账报告在抽样订单中完全一致。
- [ ] 微信、支付宝或银联的商户号、证书、回调验签、退款、关单与日对账已验收（如启用外部支付）。
- [ ] 外部支付回调可安全重放；未知回调、验签失败和金额不符均被拒绝并留审计记录。
- [ ] 发票、结算周期、供应商对账、差错处理与人工退款审批规则已由财务确认。

## D. 可靠性与安全

- [ ] `npm run quality` 在待发布提交上通过；生产依赖审计无高危漏洞。
- [ ] 生产环境健康检查正常，数据库备份成功且已完成一次恢复演练。
- [ ] 订单、支付、退款、供应商回调和身份认证已配置错误告警与负责人。
- [ ] 完成容量/压力测试；定义峰值并发、可接受错误率、关键接口 P95 延迟和降级策略。
- [ ] 完成权限越权、订单归属、库存并发、重复扣款、退款超额、PII 泄露的安全测试。
- [ ] 具备灰度发布、回滚版本和发布窗口负责人；禁止在生产直接修改历史迁移。

## E. 用户体验与运营

- [ ] PC、笔记本、平板、小程序 Web 客户端和 Android Web 客户端已在目标设备完成关键流程测试。
- [ ] 商品列表、详情、购物车、结算、订单、账户、售后均提供加载、空态、错误态与客服指引。
- [ ] 首屏性能、图片加载、键盘操作、移动端触控和核心页面可访问性达到验收基线。
- [ ] 客服 SOP、售后 SLA、退款审批、异常订单处理和用户通知模板已经演练。
- [ ] 备案、隐私政策、用户协议、发票与消费者权益文案经主体/法务确认。

## 发布结论

仅当 A–E 全部通过，且外部依赖项已完成真实联调时，项目才能标注为“正式商城上线”。未通过时，应保持“生产型 MVP/内测”标识并列出阻塞项。

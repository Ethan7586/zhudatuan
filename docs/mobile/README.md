## 统一商城完整界面总板

以下六张总板是同一套产品，不是 iOS、Android、微信小程序三套独立设计。三端共享业务信息架构、页面层级、组件语义、视觉令牌和接口合同；只在状态栏、安全区、系统返回、授权弹窗、支付拉起与分享能力上使用平台原生实现。

1. [浏览与选品 V2（购物车全局入口已恢复）](./design-previews/smart-wing-unified-mall-01-browse-v2-cart-restored.png)：首页、分类、搜索筛选、商品详情。旧版保留用于设计变更追溯。
2. [购物与支付](./design-previews/smart-wing-unified-mall-02-checkout-payment.png)：购物车、确认订单、收银台、支付结果。
3. [翼码与会员资产](./design-previews/smart-wing-unified-mall-03-wing-code-assets-ai.png)：动态翼码、会员卡、卡券与实体券、AI 福利洞察。
4. [订单与售后](./design-previews/smart-wing-unified-mall-04-orders-after-sales.png)：订单中心、订单详情、物流跟踪、售后申请。
5. [我的与账号安全](./design-previews/smart-wing-unified-mall-05-profile-security.png)：我的、个人资料、账号认证、登录设备。
6. [注册登录与关键状态](./design-previews/smart-wing-unified-mall-06-auth-states.png)：登录、普通员工注册、注册成功、资格与异常状态。

这 24 个界面覆盖第一阶段完整主链路。后续详情页（地址、发票、收藏、评价、客服、售后进度、隐私授权等）应从这六张板的组件与状态继续展开，不另起视觉体系。

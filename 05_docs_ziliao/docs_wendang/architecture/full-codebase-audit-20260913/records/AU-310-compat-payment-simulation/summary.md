# AU-310｜Compatibility 测试支付模拟

模拟路由只在 development/test 注册，handler 还要求 APP_ENV 与 AUTH_MODE 同时匹配；生产请求在路由层返回不存在。模拟数据表启用 RLS、撤销浏览器表权限，余额、点数、代金券与支付模拟事实均携带明确测试语义；真实支付渠道或外部提供方不会在该链路调用。混合支付在一条数据库事务内锁定订单及每个被消费的账户、代金券或点数钱包，并要求各支付份额严格等于订单应付金额。

发现 F-0236（P2）：充值、测试权益发放和混合支付的幂等查询与最终唯一键写入之间没有请求键事务锁或重读。相同幂等键的并发请求可让后一个事务在等待资金/订单行锁后撞主键并失败，而非复用首个响应；事务回滚可避免重复资金事实，但重试契约不稳定。该结论需第二轮独立复核。

未发现 P0。因审计工作树缺少 Vitest 依赖，未执行测试；现有验证文件覆盖输入与路由 target 边界，未见并发幂等覆盖。

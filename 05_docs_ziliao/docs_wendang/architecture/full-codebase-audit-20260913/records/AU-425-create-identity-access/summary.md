# AU-425｜身份与访问初始模型

## 范围与方法

- 主审文件：`02_platform_pingtai/database/supabase/migrations/20260821013000_create_identity_access.sql`。
- 交叉核对：后续身份、会话、范围、角色和权限 lifecycle 迁移。
- 本批为静态迁移语义与调用关系审阅；未执行数据库重放或线上操作。

## 运行结论

迁移建立身份主对象、凭据、联邦身份、微信授权、会话、一次性挑战及其密文/投递记录、认证强度、登录限流和注册策略关系。凭据主体采用散列/密文与版本字段；联邦身份、挑战、会话的状态和时间关系均有完整性约束。

访问域建立权限、角色、角色权限、membership 角色、范围授权、覆盖授权与决策审计。后续 migration 持续写入权限/角色/范围关系并在 `identity`、`access` schema 上使用这些对象。全部初始表统一启用 RLS。

## 审计结论

- G0：身份认证和授权判定的基础数据模型，不是删除候选。
- 本批未新增 P0–P3；未重放迁移，实际 RLS/ACL 与数据状态未验证。

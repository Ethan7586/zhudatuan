# AU-365｜Supabase 注册会员身份

`20260812230000_registered_member_identity.sql` 建立手机注册身份表、验证码挑战、仅 storefront 的员工邀请和本地登录候选 RPC。注册事务在单次数据库调用内验证未消费/未过期验证码、有效邀请码及其 role/企业/商城归属，再创建用户、成员、手机别名、密码凭据、storefront membership、self 范围和初始福利账户；该链路不接受管理员或 Owner 角色输入。Commerce API 的注册路由执行手机号规范化、口令哈希、PII 加密与短信投递，并调用这些 service-role RPC；正式入口默认由 `SELF_REGISTRATION_ENABLED` 关闭。

本轮独立复查确认既有 F-0234（P2）：挑战创建在手机号十五分钟五次或 IP 一小时二十次后返回 false，错误验证码最多累计五次；路由将创建失败转换为 429。该事实与项目既定的“不保留注册/验证码限流、锁定或冷却”规则直接冲突。未发现 P0；没有把静态配置开关或测试环境当作线上运行证据。

该迁移归 G0：注册身份、邀请码约束和登录候选的真实数据职责；F-0234 仍需在后续独立修复批次处理。本单元未执行注册、短信发送、测试或任何数据库写入。

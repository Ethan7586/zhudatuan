# zhudatuan 主打团 · Logo 筛选结论

## 保留

只保留 1 个现有方向，不为凑数保留次优稿：

### H0 · 评审板标题字形

- 内容：`zhudatuan 主打团`
- 字体：Noto Sans SC
- 字重：700
- 字距：`-0.01em`
- 保留原因：这是 Ethan 已明确打满分的字形；中英文属于同一套骨架，克制、稳定，没有图腾负担。
- 权威像素参考：`reference/approved-wordmark.png`
- 权威矢量参考：`reference/approved-wordmark-outlined.svg`

## 淘汰

- 所有独立图形标：语义牵强，离开解释后像通用功能图标。
- W1–W8 改字方案：破坏了已经成立的字体骨架，小尺寸可读性下降。
- T1–T5 替代字体配对：可用于排版研究，但没有一套优于 H0，不进入 Logo 决选。

## Codex 新方案 · Equal-Width Lockup

只重新设计中英文关系，不重新设计字符：

- `zhudatuan` 在上，`主打团` 在下；
- 英文缩放至中文字组的同宽，两行形成稳定矩形；
- 保留每个字的原始轮廓、字重和内部字距；
- 无图标、无外框、无底板、无装饰线；
- 40px 以上使用上下组合，紧凑页头与 24px 场景使用原始横排组合。

主方案：`zhudatuan-主打团-codex-primary.svg`

横排备用：`zhudatuan-主打团-codex-horizontal.svg`

## 推荐主图标 · Z

主图标使用 `Z`：它同时对应 `zhǔ` 与 `zhudatuan` 的首字母。造型采用连续折带结构，保留蓝色层次、圆角容器和强轮廓，但不再沿用语义错误的旧字母。

- 无框品牌图标：`icons-z/zhudatuan-z-mark.svg`
- 单色品牌图标：`icons-z/zhudatuan-z-mark-ink.svg`
- 应用图标：`icons-z/zhudatuan-z-app-icon.svg`
- 已输出 16、24、32、64、128、256、512、1024px PNG。

获批字形中的单字 `主` 降为中文场景备选，不再承担全局主图标。

- 无框品牌图标：`icons/zhudatuan-主打团-icon.svg`

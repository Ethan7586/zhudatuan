## 运行结论

schema-v2 将商城页面、组件、动作和文本限制收敛为严格 JSON 契约，并为合法 v1 快照提供确定性投影。版本表仍是唯一的 storefront 权威：中心读取会投影历史配置；变更入口执行成员授权、范围校验、幂等、乐观并发和不可变版本写入，支持创建、保存、发布与恢复。发布同时推进 head 并激活商城，审计记录变更来源。

所有低层验证、投影和写入原语均不直接开放，受限入口仅授予 service role。schema-v2 契约测试覆盖投影、无效配置、创建、保存、发布和恢复。固定基线仍未找到 canonical 构建器 RPC 的仓内运行消费者，而 Commerce 存在另一体验模型，因此延续 DC-0056/G1。

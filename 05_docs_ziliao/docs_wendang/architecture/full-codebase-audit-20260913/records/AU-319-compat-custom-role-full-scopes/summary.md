# AU-319｜Compatibility 自定义角色与完整范围

迁移把自定义角色、角色状态和全部组织范围类型纳入同一服务端模型。范围触发器验证平台、分销商、租户、企业、商城、供应商、品牌、门店、部门及 self 均属于成员可见的组织图；`api_actor_can_grant_scope` 只允许精确范围或其明确下游范围继续委派。

自定义角色创建、编辑和停用都拒绝 Owner 与系统不可编辑角色；非 Owner 只能赋予自己当前有效且未被 deny 的权限，不能修改自己已持有的角色。停用会撤销既有角色分配；既有角色权限触发器会使受影响成员的授权版本失效。权限命令中心按调用者可委派的实际范围返回成员、角色和范围选项。

HTTP 管理入口在 `adminRouter.ts` 注册；`customRoleRoutes.ts` 分别要求 role.read/create/update/delete、重新验证和服务器拥有的操作者证据。关联测试覆盖读权限、重新验证、输入去重、clone 与手工权限互斥、启用/停用权限区别。审计工作树缺少 Vitest 依赖，未执行测试。

未发现本模块新增 P0–P3 问题或删除候选；自定义角色、范围验证和命令中心投影均有真实运行职责，结论为 G0。

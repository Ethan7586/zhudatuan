# 商业资源关系模型

## 原则

供应商、品牌和门店属于经营关系，不等同于行政隶属。它们可能跨商城、多对多授权，因此不能使用单父节点组织树替代关系表。

## 推荐实体

- `brands`：品牌主体及状态。
- `stores`：线上/线下门店、履约或核销能力。
- `supplier_brand_bindings`：供应商可经营的品牌。
- `brand_store_bindings`：品牌与门店的归属或授权关系。
- `mall_supplier_agreements`：商城与供应商的供货、结算和有效期。
- `mall_brand_authorizations`：商城可销售的品牌及授权证据。
- `store_org_unit_bindings`：门店服务哪些集团、商城或区域。

## 权限映射

权限绑定仍可使用 `supplier / brand / store` 作为资源范围，但命中逻辑必须查询这些关系表，不能假设祖先关系。跨租户合作必须经过明确协议记录，不能因为共享品牌名称自动放行。

## 本期处理

共享契约中保留 `brand` 和 `store` 范围编码，但在真实表与校验路径上线前继续拒绝写入。这是有意的安全默认。

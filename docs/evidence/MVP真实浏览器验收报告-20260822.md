## 微信支付资源判定

`/Users/Ethan/Desktop/Projects/Shop/config/payment` 包含证书与私钥文件，但 README 明确说明这些只是接口需要携带的商户证书。当前源码运行时还要求 `WECHAT_APPLICATION_CONFIG_REF`、`WECHAT_PAYMENT_CONFIG_REF`、`WECHAT_IDENTITY_CONFIG_REF`，并从密钥存储读取应用和支付配置。因此仅凭该目录不能完成真实微信支付验收。

真实支付未执行，原因不是主动跳过，而是业务链路在支付前已经被“测试商品不可购买”和购物车同步失败阻断。即使后续打通，最终提交真实订单或扣款前仍需单独确认测试金额、收款商户和退款方案。

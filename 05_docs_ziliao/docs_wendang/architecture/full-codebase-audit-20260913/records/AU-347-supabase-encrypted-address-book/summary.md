# AU-347｜Supabase 加密地址簿

`20260725100000_encrypted_address_book.sql` 建立按 tenant、企业、商城和用户归属的地址簿；数据库仅保存不透明 `recipient_cipher` JSON，单用户/商城默认地址由部分唯一索引保证。读取与写入 RPC 均以完整服务器身份范围过滤，跨属主更新因 upsert 的范围条件不会写入并返回地址不存在；成功写入会产生审计事实。

当前地址路由要求 PII 加密密钥：Worker 以 AES-GCM 加密收件人字段后才调用写入 RPC，读取后只在 Worker 解密并返回给当前会话；订单创建也独立加密其收件人快照。该迁移具有真实运行调用与敏感数据边界职责，归 G0。

未发现新增 P0–P3 或删除候选。未读取真实地址、运行 RPC 或数据库迁移。
